# 時事補充

一則＝一個節日或時事（例：11.11 單身節）。只放**單字說明＋簡單句子＋金句**，不做完整課程。

## 檔案

- 資料：`data/news/<YYYY-MM-DD>-<英文主題>.json`，檔名就是 id，列表依 `date` 新的在前。型別見 `src/news/types.ts`。
- 圖片：`public/news/<YYYY-MM-DD>/`（主圖、商品小圖）。大圖先用 `sips -Z 480` 縮小。
- 頁面：`/news/<id>`、投影片 `/news/<id>/present`、列印 `/news/<id>/handout`（`src/news/NewsPages.tsx`；投影片外框共用會話課的 `SlideShow`）。
- PDF：dev server 開著時跑 `scripts/gen-handout.sh news:<id> <port>` → `public/handouts/news-<id>.pdf`。
- 網址是 HashRouter：`http://localhost:<port>/#/news/<id>`。

## 內容規格（11.11 老師定下的）

1. **導言 intro**：一段就好，短。泰文寫 `<<泰文|拼音>>`，會自動顯示成「泰文（拼音）」，中文意思另外加括號。
2. **圖片文字 image**：來源文章的主圖＋圖上文字逐句（th／rom／zh）。
3. **單字說明 image.words**：從圖片文字裡挑字，**列表呈現，不用卡片**；每個字：泰文、拼音、中文、構詞 note（例：คำ 話＋คม 鋒利），**一定附一個生活化例句 ex**。不放 emoji、不標 ★。
4. **不要另外的「單字」區**：有簡單句子就夠了。
5. **簡單句子 sentences**：6–8 句，短、口語、跟主題有關（單身、購物…）。
6. **金句 quotes**：從來源挑 4–5 句，優先**有泰國文化的**（泰國品牌、押韻、雙關）。
   - **解說要短**：只講梗本身（品牌是什麼、哪兩個字押韻、雙關的兩個意思），講完就停。
   - 不要加「句型結構教學」「學生可以套這個句型造句」「字面是…意思是…」這類延伸說明；不要加額外小知識（例：月份字尾天數）。
   - **太難解釋的刪掉**（例：วันพระไม่ได้มีหนเดียว 要講佛日＋俗語原意，被刪）。
   - 品牌梗配**商品小圖**（`image` 欄位，96px 放在解說框左邊）。
7. **資料來源 source**：附原文連結；只節錄金句，不整篇轉貼。主圖標 credit。

## 顯示規則

- 拼音、中文、喇叭開關：時事補充頁**關掉就收起來、後面補位**（`display:none`），和會話課保留空位不同（`src/news/news.css`）。
- 投影片分頁：封面（導言）→ 圖片文字 → 單字說明一頁 2 個 → 簡單句子一頁 4 句 → 金句一句一頁。
- 講義：照當下開關印，喇叭不印，主圖縮小、卡片不跨頁。

## 找素材

- 搜尋泰文關鍵字（例：`วันคนโสด 11.11 คำคม`）；X／TikTok 抓不到，請老師貼截圖。
- 追星：Sanook／Thairath／Khaosod 的 บันเทิง 版；旅遊：ท่องเที่ยว 版、TAT News、Pantip บลูแพลนเน็ต。

## 完成後

`npx tsc --noEmit`，用瀏覽器看課程頁、投影片（逐章）、列印頁，重產 PDF。拼音照 thai2english 寫法，不確定的字列給老師確認。
