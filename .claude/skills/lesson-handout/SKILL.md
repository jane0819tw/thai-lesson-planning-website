# 認字課 PDF 講義

**一個單元一份**（L1–L5 一份，和學生開放權限的單位相同，學生不用自己彙整各課）。程式在 `src/components/HandoutPage.tsx`；每課內容直接用課程頁的排版（`<LessonPage printLesson={l} />`：不顯示返回連結、按鈕、目錄、互動練習，區塊全部展開）。樣式在 `src/styles.css` 的 `.handout`／`.h-*`／`.hcell`。2026-11-05 和老師定的。

課程內容本身是 reading-lesson skill 的事；投影片是 lesson-slides。這裡只管列印版面與作業。

## 列印按鈕放哪

- 認字課（之後的會話課也一樣）：放在**單元層級**，不放在各課頁。目前在認字課列表（單元最後一課、作業複習後面的「🖨 L1–L5 列印講義」）和學生「我的課程與作業」的單元標籤旁邊（`BookingPage` 的 `.bk-print`）。
- 歌曲、影片是延伸課程，列印按鈕維持在各自頁面（`src/study/PrintSheet.tsx`），不要動。

## 流程

1. dev server 要開著，port 用實際的（`lsof -nP -iTCP -sTCP:LISTEN`）。
2. 輸出：`scripts/gen-handout.sh <單元> <port>` → `public/handouts/reading-<單元>.pdf`。
3. 檢查：PDF 轉圖片（`osascript -l JavaScript .claude/skills/reading-lesson/scripts/render-pdf.js <pdf> <scratchpad>/pages`，資料夾先建），用 `ffmpeg -pattern_type glob -i 'p*.jpg' -vf "scale=220:-1,tile=13x2" -frames:v 1 sheet.jpg` 拼一張總覽，再放大看有問題的頁。看：每份作業一頁放得下、組成圖一整列、卡片和表格沒被切開、標題沒留在頁尾、沒有播放按鈕。
4. 回報頁數與每課的頁碼範圍；commit 等使用者說。

## 已定的規格

- **順序**：封面（單元名稱＋各課標題）→ **單元複習作業**（`ReviewSheet`，在 L1 前面）→ 每一課：內容（課程頁全部區塊，含**小結**、**補充**的梗圖與圖片；不含互動練習）→ 這課的作業。每課、每份作業都另起一頁。
- **一個章節盡量一頁**：每個章節（子音、聲調、單字、補充…）從新的一頁開始，標題不會留在上一頁的底部；**單字、練習、小結放同一頁**（都短，L2 老師：單字、多音節、小結同一頁）。列印時單字一列 4 個（L5 ถั่ว 才不會一個人掉到下一頁）。
- **補充**：不換頁，直接接在前一章（小結）後面；一格佔一半寬、兩格一列，圖片最高 46mm（L1 老師：高度不要那麼大、空間夠就放前一頁）。放不下的卡整張移到下一頁，不會被切開。
- 內容部分列印時縮成 0.82 倍（`.handout > :not(.h-sheet)`），作業不縮。播放鈕一律不印。
- **練字格放在課程內容裡**（L2 老師：不要到最後才有一頁描字作業）：
  - 子音：一個字母一列，左邊字母卡（橫的：字母｜圖示｜名稱、拼音、中文、類型），右邊練字格。
  - 子音的例字（L4 起）放在練字格**下面、橫向一排**，字要夠大（1.6rem）。
  - 母音：母音卡上排是「母音｜練字格（短音、長音各一列）」，下排是「拼讀表｜例字」；特殊母音沒有拼讀表，例字橫排佔滿整列（`VowelCard` 的 `aside`）。
  - 練字格一列 **10 格**：描字 3 格＋空白 7 格（`TraceRow`），不放黑字示範格，因為左邊卡片已經有大字。
  - 描字用**筆順播放器底字的點虛線描寫字體**（LayijiTrace），字級、基線同播放器；寬的母音用筆順資料的 `fs`／`gy` 縮小，同一列的空白格格線跟著縮。格子可視範圍從 y=0 開始，ไ ใ 的高頭才不會被切掉。**不要筆順圖**（L1 老師）。
- **單元複習作業**（`ReviewSheet`，資料：各課 JSON＋`data/reading-chart.json`）：
  - 第 1 頁：兩個鍵盤（一般、Shift，Kedmanee 排列），下面中子音、高子音、低子音 LCp、低子音 LCs、長母音、短母音、複合母音、特殊母音的空格（格數＝整個課程這類有幾個），讓學生寫出來、在鍵盤上圈出位置。
  - 第 2 頁：這個單元的拼讀規則填空（說明裡的 `[[答案]]` 印成空格，聲調表只印表頭和列名）。
- **作業 聲調填空（L1）**：只在這課子音全是中子音、而且有聲調表時自動出現。第一聲（子音＋อ）給好，第二～五聲空白；表頭的聲調符號**單獨畫、不帶 อ 載體**（`MarkGlyph`）。
- **其他作業寫在課程資料 `worksheets`**（`LessonWorksheets`，一份一頁，右上姓名日期；L2–L5 老師 2026-11-09 定）：
  - `spell` 拼字表（L2、L3）：直欄學過的子音、橫欄這課的母音（短、長），第一列示範。表頭母音用單色字（雙色 `VowelText` 列印時 อี 會被切掉）。
  - `toneFill` 聲調填空（L2）：子音＋母音，短音、長音各一列；不加符號那格給好，第一聲 ✕ 灰底，短音第五聲標 (x)。
  - `toneJudge` 判斷聲調（L4）：中、高子音混合的常用字，圈中／高、長／短，寫聲調符號、第幾聲；`answer` 存答案，不印。
  - `split` 拆字（L5）：**生活常見的字**，只用學過的子音、母音，沒有尾音；一個音節一列，第一個字 `demo` 示範。
  - 作業表格可以跨頁（列不切開），不會整張被推到下一頁只留標題。
  - 答案一律請老師核對。
- **聲調符號**：說明、表頭裡的聲調符號一律單獨畫（`MarkGlyph`），不寫符號名稱（L2 老師：「加上 ไม้โท、ไม้ตรี」改成直接顯示符號）。

## 注意

- headless Chrome 要用 `[::1]`（vite 只聽 IPv6）和獨立的 `--user-data-dir`，腳本已處理。
- `src/song.css` 的歌曲講義列印規則原本會藏掉整個網站，已改成只在頁面上有 `.sprint` 時才藏。不要再寫全域的 `#root { display: none }`。
- A4 寬度會觸發 `max-width: 760px` 的手機版樣式（例如組成圖換行），要在 `@media print` 裡蓋回來。
