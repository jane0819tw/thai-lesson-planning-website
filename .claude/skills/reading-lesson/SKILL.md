# 認字課程：一課的製作與優化規格

整理自 L1–L15 的調整（2026-10-19～10-30）。目標是讓新的一課**第一版就做成老師要的樣子**，不用再逐項回頭修。

一次只做一課。每課照「流程」跑完、對過「第一版檢查清單」，交給老師看，改完再做下一課。

## 交接：下一課要帶進去的東西

做新的一課前先看這裡，做完就把用掉的項目刪掉，並把這一課要留給下一課的東西補上來。

- **L16** 待老師回覆：講義第 5 頁的 CP 香腸包裝圖（A–D）要怎麼用。
- **L18** 第一版已做（2026-11-02），待老師看。新增 `numerals` 欄位與 `NumeralTable` 元件、๐–๙ 筆順草稿（`data/strokes/chars/`），要和 L18 一起 commit。待老師確認：๐–๙ 筆順（特別是 ๐ 的方向、๔ ๕ 底部、๙ 分兩筆）。
- **L19** 第一版已做（2026-11-02），待老師看。新增 `readingCases` 欄位與 `ReadingCases` 元件。L19 講義第 14 頁**沒有**複習 L18 的練習，最上面是「ร 已經扮演的角色」總表（放「說明」）；待老師決定要不要改放「複習」。
- **L20** 第一版已做（2026-11-02），待老師看。沿用 L19 的 `readingCases`，新增 `cases[].symbol`（大字符號）、`words[].full`（縮寫全名，音檔念全名）；`gen-audio.py` 把 ฯลฯ 念成 เป็นต้น。講義沒有作業頁，`homework` 8 個全從多音節練習挑；第 18 頁沒有複習。補充的三張圖（ตักบาตร、考艾動物園、ไอ้สัส 梗圖）是從講義裁的第三方圖，公開前要確認。

## 流程

1. **讀講義**：PDF 放在 `data/handouts/`（不進版本控制）。用 skill 附的腳本轉成圖片和文字，輸出放 scratchpad：
   ```bash
   osascript -l JavaScript .claude/skills/reading-lesson/scripts/render-pdf.js data/handouts/<講義>.pdf <scratchpad>/pages
   ```
   先看 `text.txt` 找出這課在哪幾頁，再用 Read 看那幾頁的 JPG。抽出的泰文常掉字，**泰文一律以頁面圖片為準**。
2. **對照講義建資料**：照下方「講義 → 課程資料」逐塊填 `data/lessons/lesson-NN.json`（形狀見 `src/types.ts` 的 `Lesson`，放進去就會出現在課程列表）。可以拿最接近的課當範本：聲調規則看 L9、清尾音看 L10、母音變形看 L11、複合子音看 L13。
3. **對過「第一版檢查清單」**。
4. **build 與看畫面**：`npm run build`（含 `tsc --noEmit`）要過。`npm run dev` 後用 Chrome 開 `/#/reading/lesson/lesson-NN` 與 `.../homework`，用 JS 捲到各區塊截圖檢查；作業頁可用 JS 讀出各題標題與題數。`resize_window` 縮不了視窗（頁面仍回報 1920 寬），手機版只能靠 CSS 判斷，回報時要說沒實測。看完關掉自己開的分頁。
5. **生成音檔**：見下方「音檔」。
6. **更新清單**：`npm run inventory` 重新產生 `docs/curriculum-inventory.md`。
7. **交給老師看**：照「回報時要講清楚」列出。不要自己把 `status` 改成 `ready`；commit 等使用者說再做。
8. **commit 前先更新這份 skill**：把這一課老師要求的修正、自己判斷之後也適用的做法，寫進對應的段落（不是只記在交接區），讓下一課第一版就照著做。skill 的修改跟課程內容放在同一個 commit，回報時列出這次補了哪些規格。

## 內容規格

### 分頁（自動依資料出現，不用設定）

順序：複習 → 母音 → 說明 → 小單元（L13-1、L13-2…）→ 尾音 → 子音 → 單字 → 練習 → 補充 → 互動練習。沒資料的分頁不會出現。捲到哪個區塊，左邊目錄那一項會變色。

順序寫在 `LessonPage.tsx` 的 `lessonTabs()`，投影片模式也照這個順序。要照講義改順序就用資料欄位（L1：先概念、再子音、最後聲調）：
- `rules[].at: "concept"`：說明卡放進「基本概念」區塊（和音節組成圖 `diagram` 一起排最前面），`diagram.after` 填說明卡 id，組成圖就排在那張後面。
- `rules[].at: "consonants"`：說明卡放在「子音」區塊最上面。
- `tonesAfterConsonants: true`：「說明」（聲調總覽、聲調表）排到子音後面，改叫「聲調」。

要做投影片（`slides: true`）用 lesson-slides skill。

- **複習**（`review`）：上一課講義上的複習練習，上課一開始先做；格式同補充卡（`title`＋`lines`）。不要放在 `extras`。
  - 一張總表一張卡，聲調表放 `toneTables`（表格本身 `title` 留空，免得和卡片標題重複）；規則句寫在表格 `note`。尾音字母**全部列出、但用小字**：放 `finals`（一個音一列，`main` 主要字母加底線、`others` 同音字母），不要用 `lines` 的大字（L13 老師覺得太大）。字母表預設收起，卡片標題右邊有「尾音字母 ▾」按鈕展開（三個分頁共用同一個開關）。有聲調表或圖片的卡會自動佔滿整列。
  - 聲調總表**不要叫「開音節」**（講義沒這個詞），照老師的說法叫「拼讀規則」（L13）：「複習：子音＋母音拼讀規則」「複習：子音＋母音＋清尾音拼讀規則」「複習：子音＋母音＋濁尾音（3 音 26 字）拼讀規則」；區塊名稱 `reviewLabel: "複習拼讀規則"`。
  - 複習有兩張以上的卡時，畫面自動變成**分頁切換**、一次看一張（老師覺得三張表上下排可讀性差）；`tab` 填分頁按鈕的短名稱（例「子音＋母音＋清尾音」）。每個分頁高度一樣、聲調表位置一樣（老師不要切換時高度跳動），這是程式自動對齊的，不用調資料。
  - 講義「上一課．複習」頁上的非練習內容（L12 的字母依發音分組總表）**放回那一課**的「補充」（`memes` 一張全寬卡，從講義裁圖），不放下一課的複習。
  - 複習裡的聲調表也會生成音檔（`gen-audio.py` 會收 `review`、`extras` 的 `toneTables`）。
  - 「哪一個拼法正確？」這類二選一題用 `choices`（`[{ options: [A, B], answer: 0|1 }]`，`lines` 留空陣列），畫面是 A／B 表格、點選顯示對錯，有「顯示答案」「重來」（L12，老師覺得純文字列點很醜）。講義上兩個都是真的字時（例 สาม／สาน），回報時請老師確認答案。
- **不要獨立的「聲調表」分頁**：聲調表放 `toneTables`，會出現在「說明」最下面；需要放在某張說明卡裡就用 `rules[].toneTable`，放在母音前就用 `vowels[].preface[].toneTable`。
- 「這是什麼意思」已改名為 **「補充」**（`memes`）。`extras` 的分頁也叫「補充」，兩個都有會同名，盡量只用一種。
- 練習只有一組時，區塊名稱自動變成那組的標題；兩組以上叫「練習・句型」。

### 說明卡 `rules`

- 規則有好幾點時，`body` 用 `\n` 分行，畫面會列點（L4、L6、L7 改過）；`- ` 開頭的行是上一點底下的小點（L16-1：ริ 念 ริ、ร 念 ระ 各一點，各帶一個例字）。
- 本課重點用 `**文字**` 標示（粗體＋主色），一課一兩處就好；講到規則的關鍵字也標（L1：由左至右、分隔句子、單獨一個 g 念不出來、同音字母、聲調規則）。
- **單字不顯示拼音**：認字課的單字、例字、練習在課程頁、投影片、講義都不顯示拼音（`vocab[].roman` 可以留著，畫面不用）；子音名稱的拼音（gor gài）照常顯示（L1 老師 2026-11-05）。
- **小結 `recap`**（每課都要有，第一版就寫草稿給老師改）：放在單字、練習之後、補充之前。**點數跟 `summary` 一樣、一一呼應**（summary 三點就三點，`point` 用 summary 那一點的主幹，括號裡的細節不用寫，L1：「建立整體概念」），`items` 列細項（這課的字母、規則一句話、易混淆處），重點字 `**…**`；畫面上主點開頭是綠色勾（表示學會了）。只列上課有講的。講規則的點直接放一小張聲調表（`toneTable`，從本課聲調表挑一列，L1：ก 那一列），不用再寫成文字。單獨的聲調符號不要直接打（會出現虛線圓圈），寫名稱 ไม้เอก、ไม้โท…（L1 老師 2026-11-05）。
- L1 老師拿掉了「講義的拼音符號」說明卡（封面也不提）：拼音規則不用另做一張說明卡。
- **用詞：「音節」不是「單字」**。講組成（子音＋母音＋尾音＋聲調）時一律說「一個泰文**音節**」，組成圖 `result` 寫「音節」（L1 老師 2026-11-05）。
- 說明盡量用學生熟的注音類比，少用英文類比：子音單獨念不出來 → 「就像注音 ㄍ 單獨念時其實念成 ㄍㄜ」（L1）。還沒教到的概念（母音以 อ 當載體）不要提前放進第一課。
- 抽象規則配一個實例：說明卡 `sentence` 放例句、逐詞標中文（L1 文字系統用 สวัสดีค่ะ ฉันชื่อเจน 說明由左至右、空格分句）。
- 說明卡要等學生看過例子再講時，用 `afterLetter` 排在那個字母後面（L1：看完 ก 再講子音怎麼念、同音字母）。
- 子音的「發音」需要說明時填 `soundNote`，取代「發音 X」（L1 อ：當子音不發音，當母音發 or 音）。
- 聲調表的 `note` 簡短就好（L1：「以 ก、จ 為例」），規則句不要塞在表格說明裡。
- 後面的課重複前面規則時，寫「同 L6 低子音 LCp 的規則。」再列點，不要整段重抄成長段落。
- 講義把一課分成幾個小單元（「L13-1.複合子音」「L13-2.อ นำ ย」）時，每個小單元自成一個區塊，名稱照講義（`L13-1 複合子音`）：說明卡、`clusters`、練習組都填同一個 `unit`，就會排進那個區塊，不再有「說明」「練習」區塊（老師：說明底下突然出現 L13-2 不一致；多音節練習要併入對應的區塊）。區塊名稱已經寫了小單元，說明卡 `title` 留空，練習組標題就叫「多音節練習」。
- 講義只有結構圖和表格、學生看不出規則時（L16-1 Double Grouping），在小單元最上面加一張說明卡：`unit` 填小單元、`at: "top"`、`title` 留空，會排在副標下面、結構圖上面。一個音節一點，講三件事：表上列的字母是什麼（常見的 C1）、和前一課規則差在哪（C1อ vs L15 的 C1ะ）、容易從前一課帶過來的錯（第 3 個音節不加 ห）。講義沒寫的說明先問老師要不要加（L16 老師同意加）。
- 講義只有表格、沒有說明文字時，不用硬寫說明卡，規則句放 `summary` 就好（L11）。

### 聲調表 `ToneTable`

照講義排版：

- `corner: true`：標題放表格左上角。
- `rows[].group`：最左欄子音類型（中子音／高子音／低子音 LCp／ห LCs），相鄰同 group 會合併成一格。講義把 LCp、LCs 合成一格時寫「低子音 LCp、LCs」。
- `tint: true`：短母音列淺藍、長母音列淺黃；`tint: "long"`：全部淺黃（有清尾音時一律依長母音規則，L10、L11）；`tint: "short"`：全部淺藍（有濁尾音時一律依短母音規則，L12）。
- `rows[].mark: true`：講義整列橘底的重點列（L12：低子音＋長母音是例外），表格 `note` 寫一句為什麼標橘底。
- `fill: true`：ห 補齊的那一列（黃底藍字），空字串＝空白格。
- 不發音的格子寫 `x`、`不發音`、`用ห補` 或「用…」開頭的說明，音檔腳本會自動略過。
- 多種子音一起比較時，先放本課的子音，再放對照組（L6：先 LCp 再高子音）。
- 講義的表沒標題時自己取一個短標題，說明這張表在比什麼（L11：「母音變形後的聲調（กัน／กาน）」）。
- 複習總表放在補充卡 `extras[].toneTables`，標題用「複習：…」（L9：「複習：子母音聲調規則總表」）。

### 子音、母音、尾音

- 子音卡的範例字會顯示播放鈕；子音圖示在 `data/icons.json`，優先用 Twemoji，找不到貼切的就自繪 SVG 放 `public/icons/custom-*.svg`（例：ฑ 戴金冠的舞者、ย 守門巨人、ณ 小沙彌）。
- 母音分組用 `heading`；只有短音的小卡連續標 `inRow` 排同一列；單字要放在某組母音之後就設 `vocabAfterVowel`。
- 尾音總表（「N 音 M 字」＋音節結構圖＋規則句）用 `finalsIntro`：`true`＝清尾音預設表（L10）；其他尾音課填 `{ kind: "濁", rule: "short", rows: [...] }`（L12），音數、字數自動算。
- 一個尾音的字母很多時，老師要**分組、一組一列**（L12：g ก；คฆข／p บป；พภ；ฟ／t ดตฏฎ；ทฑธฒฐถ；ซสศษ；ชฌ；จ）：`finalsIntro.rows[]` 用 `{ sound, lines: ["ก", "ค ฆ ข"] }`，尾音卡 `finals[].lines` 填同樣的分組，兩處都會一組一列顯示。分法照老師給的，不要自己合併。
- 尾音課：`finals` 每個尾音一張卡（含 `mouth` 口型說明），`vocab[].group` 對到 `finals[].group`，單字會排進對應的尾音卡，不另開「單字」分頁。
- **母音加尾音的變形**（L11 `vowelShifts`）：照講義「母音｜加尾音｜例字」左右對照。
  - `finals` 用 x 標尾音位置（`-ัx`、`เ-็x`），沒填＝講義的「/」；`changed` 標講義橘底的格子；`note` 放老師手寫的補充（例：ผม＝ผ＋โ-ะ＋ม）。
  - 一個母音有兩種寫法（เ-อ → เ-ย、เ-ิx）時**分兩列**：下一列另一邊填 `null`、本邊 `vowel` 留空字串，母音格會自動合併。
  - 例字畫面上一個一列。例字也要放進 `vocab`（音檔、中文、聽音選字都從 vocab 來）；有 `vowelShifts` 就不另開「單字」分頁。

### 梵文母音 `sanskritVowels`（L14）

- 講義「梵文來的母音」表：一個字母一組，`readings` 一個念法一列（`sound`、例字 `word`、分音節念法 `split`），講義的「/」不填 `word`，「現今不使用」設 `unused`，淺黃底的格子設 `mark`。放在「母音」區塊（`vowelIntro` 之後），`vowelIntro` 的 `focus` 填 `sanskrit`。
- 例字也要放進 `vocab`；有 `sanskritVowels` 就不另開「單字」分頁。念法（รึ、ริ…）的音檔走 gTTS。

### 複合子音 `clusters`（L13）

- 講義「C1｜C2｜組合」表：`rows` 一個 C1 一列，`group` 寫中／低／高，`tint` 照講義分色（yellow／gray／pink），講義劃掉的組合放 `crossed`（畫面加刪除線）；`c2` 合併成一格；`rules` 是右邊的規則句（音節結構圖自動畫 C1、C2）。
- 例字表放 `words`：`parts` 照講義拆法，用 `＋` 分段，母音和聲調符號用 `-` 標 อ 的位置（`คร＋-ู`、`ปร＋เ-ีย＋ว＋-้`，不要用 ◌，泰文字型會顯示成方框）；老師寫的分音節放 `＝` 後面（`＝มะ・พร้าว`）。
- 例字也要放進 `vocab`（中文、音檔、聽音選字從 vocab 來）；有 `clusters` 就不另開「單字」分頁。
- 同一課另一個小主題（L13-2 อ นำ ย）用 `rules` 說明卡＋`demo` 小卡放那幾個字（`sub` 中文、`speak` 播放）。

### Grouping `grouping`（L15）

- 講義每個小單元都是「結構圖＋第 1／第 2 個音節對照表＋例字表」：`grouping[]` 一個小單元一筆，`unit` 照講義名稱（`L15-1 一般 Grouping 組成結構`），自成一個區塊。
  - `c1`／`c2`：結構圖 C1、C2 下面的小字（MC/HC、LCs）；`consonants`：子音列，一格＝兩個音節合併（「符合一般 Grouping 組合結構」）；`pron`：音節發音列，講義紅字用 `**ห**`，`\n` 後面另起一行（`C2V(F)\n**＊不加上 ห**`）；`note`：表格最下面跨欄的紅字。
  - `words`：例字，`split` 照講義的「第1個音節-第2個音節」，講義整個念法標紅設 `mark`；只有部分字母標紅（L17 Double Function 的 F1）就在 `split` 裡用 `**…**`（`ผ**น**-**ละ**-ไม้`），結構圖 `boxes[].cells[].big` 也可以（`**F1**`）。例字也要放進 `vocab`；有 `grouping` 就不另開「單字」分頁。
- 講義小單元名稱容易混淆時（L15「組成以外」和「組成例外」只差一個字），**標題保留講義原名**，`subtitle` 寫一行規則當副標（「MC/HC＋LCs：加 ห」「其他組合：不加 ห」）。
- 結構圖上學生看不懂的記號（L15-2 的「!(MC/HC + LCs)」）不照抄，小字留空，用 `caption` 白話說明。
- **三個音節／自訂結構圖（L16）**：`pron` 幾格就幾個音節欄（Double Grouping 填三格）；`vowels`／`finals` 填「母音」「尾音」列，`vowels` 某格填 `null`＝上面子音格往下合併（L16-1「ริ 發 ริ／ร 發 ระ」跨兩列）；`boxes` 自訂結構圖（`cells` 一格一個記號：`label`／`big`／`sub`，`pink: true`＝講義的粉紅框）。三個音節時結構圖自動排在表格上面。
- 一個規則底下有好幾種情況時（L16-1：C1 是 บ → 寫 ริ 念 ริ；C1 是其他子音 → ร 念 ระ），老師要**每種情況自己一組**：`grouping` 每種情況一筆（同一個 `unit`），`heading` 寫「情況一：C1 是 บ」、`body` 寫這個情況的規則，各自有結構圖、音節表、例字表；講義合併成一格的（「ริ發ริ／ร發ระ」）拆開寫到各自的表。最上面的說明卡（`at: "top"`）只留各情況共通的點，分情況的地方寫「見下方情況一、情況二」。講義本來就分表（常用／其他）時照講義的分法分情況。（`words[].group` 可以在同一組裡再分例字表，目前沒用到。）
- 同一個小單元有好幾張結構圖＋表（L16-2 的 Cำ 和 ประ）：`grouping` 放好幾筆、`unit` 填一樣，依序排進同一個區塊；只有「音節發音」一列的表設 `pronOnly: true`。講義例字前的 ＊ 用 `star: true`；＊＝補充字（L16 老師說明），vocab 要設 `noQuiz: true`。
- 單獨的 ำ 不要寫成 `-ำ`（圈圈會跑到連字號上），直接寫 `ำ`，畫面會像講義一樣帶虛線圈；副標裡要講 Cำ 時用文字說明「母音是ำ 的音節」（L16 老師把列舉的 ตำ、สำ、กำ 改成這句）。
- 講義標題寫「…單詞」（L16-2 特殊ห角色單詞）的是**要個別記的字**，不是通則：副標、summary 不要寫成「遇到 X 就加 ห」，要寫「特定單詞：…（要個別記）」，否則學生會把 ประมาณ（ประ-มาน）、ตำนาน（ตำ-นาน）念錯。
- 講義的多音節練習混在一張表、對不齊小單元時不硬拆（L15 拆了 L15-4 只剩一個詞），整組放成獨立的「多音節練習」區塊。

### 情境讀法表 `readingCases`（L19）

- 講義「情境｜讀法｜範例（例字｜[念法]｜意思）」的表（L19 a. Cรร(F) 讀法、b. ร 遇到特殊結合）：`readingCases[]` 一張表一筆，`unit` 填小單元（`L19-a Cรร(F) 讀法`）自成一個區塊；沒填 `unit` 放「說明」（L19 的「ร 已經扮演的角色」）。
- `cases` 一個情境一組：`case` 情境、`reading` 讀法（`\n` 分行、`**…**` 紅字，例 `ทร V (F)\n→ **ซ** V (F)`）；`words[]` 一字一列，`read` 填方括號裡的念法，講義標紅設 `mark`。`caseHead`／`readHead` 改欄名（講義「原-念法」寫 `原 → **念法**`）；全部沒有 `reading` 就不顯示讀法欄。`note` 放表格下方的補充。
- 講義的框圖（L19-b 的 ทร V (F) → ซ V (F)）老師要**用原圖**、放在情境格的文字下方，「原 → 念法」欄的文字照留：用 `clean` 重轉那一頁、一個情境裁一張（上下兩個框一起裁），放 `cases[].image`。講義那張表沒有框圖時（L19-a），老師要**同一個樣式**：用 `cases[].boxes` 在網頁上畫（一個陣列一個框，上面原本、下面念法，`label` 子音／母音／尾音，改變的部分用 `**…**` 紅字，例 `C｜**ั**｜**น**`）。
- 講義的「C ั F」直接寫空白＋母音符號（`[C ั F]`），不要用 ◌。
- 例字都要放進 `vocab`；有 `readingCases` 就不另開「單字」分頁。複習前幾課的例字（รัก、ครู）在 vocab 設 `noQuiz`。
- 同一個小單元可以放好幾組練習（L19「多音節練習」＋「真的假的？！」）：`unit` 一樣、`title` 不同即可。

### 大寫數字 `numerals`（L18）

- 講義的數字對照表（大寫數字｜阿拉伯數字｜念法）用 `numerals`：一個數字一筆（`digit`、`arabic`、`word`），自成「大寫數字」區塊，每 5 個一張表，大寫數字列淺黃底。有 `numerals` 就不另開「單字」分頁。
- `vocab` 放 10 個大寫數字（`thai: "๑"`、`zh: "1（หนึ่ง）"`），作業頁聽音選字就會是「聽念法、選大寫數字」。
- 音檔：`gen-audio.py` 會讓單獨的大寫數字念它的 `word`；老師說要重錄的句子，在 `FORCE_SYNTH` 把數字直接寫成念法再 `--only` 重生（L18 ฉันกินชานม ๓ แก้ว）；含大寫數字的短語（๗๐ บาท）合成時換成阿拉伯數字，引擎才會念成 เจ็ดสิบ。
- 作業聽寫可以放「數字＋單位詞」（๗๐ บาท），作業頁鍵盤按 Shift 就有大寫數字。
- 大寫數字要有**筆順教學**（L18 老師要求）：點表上的數字只打開筆順視窗、不發音（老師不要點開時發音；念法格有喇叭），資料在 `data/strokes/chars/๑.json`…。自動產生的草稿（`strokeGen`）會從尾巴開始、斷成好幾段，不能直接用：要照「從頭（小圈）開始、一筆寫完」重新串成一筆（๓ 中間那條要往下再折回；๙ 右上的尾巴另一筆），保留 `draft: true` 請老師確認。新的課有新字母、符號時也一樣要補筆順。

### 情境讀法表 `readingCases`（L19、L20）

- 講義「情境｜讀法｜範例（例字｜[念法]｜意思）」的表用 `readingCases`，`unit` 填小單元；例字也要放進 `vocab`（中文從 vocab 帶），有 `readingCases` 就不另開「單字」分頁。
- 講義左邊有大字符號框（L20 的 ฯ、ฯลฯ、ๆ）時，符號放 `symbol`（大字），名稱和中文放 `case`；講義的大標題（「有該符號的字不用念」）寫成 `reading` 或表格 `title`。
- 縮寫念全名（กรุงเทพฯ）：`full` 填全名、`read` 填分音節念法，音檔會念全名。例句（ฯลฯ 的句子）不填 `read`，會自動跨過念法欄、可以換行；例句放進 vocab 時設 `noQuiz: true`，`zh` 留空字串（L20 老師拿掉例句的中文）。
- 單獨的 ์ 不要放在標題開頭（會浮在空白上），標題寫「การันต์（不發音符號）」就好。
- 講義的「句子翻譯」（L20 แม่ชอบตีกอล์ฟ）放 `practice`（`homework: true`、每句有 `zh`），作業頁變成聽音選中文；講義沒有作業頁時，`homework` 從多音節練習挑 8 個，回報時列出。

### 練習 `practice`

| 情況 | 設定 |
|---|---|
| 雙音節短詞、多音節練習 | `third: true`（一列三個，手機兩個） |
| 較長的多音節詞 | `half: true`（一列兩個） |
| 圖卡練習（例如泰式料理） | `images: true, third: true` ＋每個 item 的 `image`（沒圖顯示「圖片待補」） |
| 只放作業頁、不放課程頁 | `homework: true` |
| 問答（一句問、幾句回答，例 L12 天氣表達） | `qa: true`：第一個 item 是問句放左邊，其他是回答排右邊 |
| 一問一答好幾組（L14 Q1–Q10） | 老師說是讓學生拼讀短句，做成清單，區塊名稱「泰文拼讀規則總複習短句練習」：`half: true`，item 依 Q1、A1、Q2、A2… 排（左問右答），`note` 填 Q1／A1；兩種回答用「 / 」分隔放同一個 item（音檔不念斜線） |

- 多音節練習每個 item 都要有 `zh`。
- 練習組是本課的主要內容時（L14 的「生活常用短句」「泰文拼讀規則總複習短句練習」），老師要**每組自己一個目錄項目**：填 `unit`（＝目錄名稱），`title` 留空，免得卡片標題和區塊名稱重複。
- 課程頁上方不再有「顯示中文翻譯」「顯示拼音」勾選框（L14 老師拿掉），中文、拼音一律顯示；練習卡有中文時右上角自動有「隱藏中文」按鈕（預設顯示），`note` 標籤（Q1、A1）顯示在泰文前面，都不用設定。
- 標 `homework` 的練習組，在作業頁的呈現由資料決定：
  - item 有 `parts`（音節拆解）→ **短句斷句題**，會計分、跟作業一起送出（L8）。第一題加 `demo: true` 當示範。`parts` 格式：`{ syl, c, v（用 - 標子音位置，例 เ-า）, m（聲調符號，沒有就省略）, t（1–5 聲） }`。
  - 每個 item 都有 `zh`（至少 2 個）→ **聽音選中文**，不計分（L10 菜單、L11 點餐練習）。
  - 其他 → 只列出來。

### 作業 `homework`（聽寫用字）

- 放 **8 個多音節詞或短語**；講義作業頁的抄寫字放前面，不夠的從本課多音節練習補（L11 補了 ใจเย็น、สามคน、มะม่วง）。作業頁只取前 8 個。
- 講義作業頁的抄寫字超過 8 個時（L14 有 10 個），老師要**全部放**：`homework` 照講義順序填，`homeworkCount` 設成字數。
- **不要放造句題**（L7、L9、L11 都拿掉了）。
- 講義作業頁的抄寫字就算是單音節（L13 的 ใกล้、กลัว、เปรี้ยว）也照放，回報時說明；抄寫字重複的（L13 มีความสุข 寫了兩次）拿掉，空位補本課另一個主題的詞（L13 補 อยากไปเที่ยว）。
- 抄寫字裡有**還沒教到的規則**時（L16 的 ประโยชน์ 有不發音的 ์，L20 才教），不放打字聽寫，換同一小單元的另一個字（換成 ประโยค），回報時說明。
- 挑的詞要確認音檔聽起來正確；聽起來不對的就換別的詞（L9 把 หมอดูเมาเหล้า 換成 หมอผี）。

### 作業頁第 1 題「聽音選字」（自動判斷，不用設定）

- 子音 ≥ 4 個 → 選字母；否則母音音節 ≥ 6 個 → 選音節；都沒有、單字 ≥ 4 個 → **選單字**（每次隨機 10 題）。
- 講義標 ＊ 的補充字（L16 ประวัติศาสตร์）在 vocab 設 `noQuiz: true`：課程頁照常顯示、有音檔，但不會出現在聽音選字，也不放 `homework`。
- 所以沒有新字母的課（聲調規則、尾音、母音變形…）至少要有 4 個 `vocab`。「互動練習」分頁也用同一個條件。

### 補充 `memes` 與圖片

- 兩張 `half: true` 的卡並排、圖片縮小；只有文字的卡設 `imageUrl: null`（沒填會顯示「圖片待補」）；只放圖可以 `title`、`desc` 留空。
- 大字泰文用 `big`；只有大字、沒圖的 half 卡會自動放大置中。
- 說明文字直接講內容，不要加「講義作業頁的推文：」這類出處前綴（L12 老師要求拿掉）。
- 補充卡 `desc` 不要自己加說明：講義上沒有的小字（圖上文字的翻譯、「泰文標價和英文標價一樣嗎？」、「要按 Shift 才打得出來」）都不放，只放標題和圖（L18 老師全部拿掉）。
- 講義裡的梗圖、截圖（L12 作業頁的 คิดถึงมากกก 推文）也照這個方法從講義裁出來用。大字太長會斷行，`big` 要縮短到一行放得下。
- `links` 目前畫面上不會顯示；講義的 YouTube 網址寫進那張補充卡 `desc` 最後一行（「廣告影片：網址」），`desc` 裡的網址會自動變成超連結、另開分頁（L16 CP 廣告）。
- 講義上的廣告詞、台詞是**一整句**時，`big` 放整句（L16 老師要「ไข่สด ซีพี」後面的 สดจริงจนจีบได้!! 也列出來），太長用 `\n` 分兩行；`desc` 再用小字逐字解釋。
- 講義「文化」區（L15）：一則一張 `half` 卡，`big` 放關鍵泰文（ตลาดน้ำ、สวัสดี），`desc` 用 `\n` 分行，圖從講義裁。講義文字不通順的地方（L15「Sawadee 擔任院長」）改寫並回報；第三方的圖（FB 貼文圖）在 `desc` 最後寫出處，回報時提醒公開前確認。
- 講義「梗圖句子／歌曲名」2×2 的圖（L13）：一張圖一張 `half` 卡，`title` 中文、`big` 泰文句子，`desc` 只寫出處（歌名、影集），不要自己加用法說明（L13 老師刪掉「มึง／กู 是很不客氣的你／我…」）。
- 講義上的圖有老師的手寫筆跡（劃線、圈字、補寫）時，用 `clean` 參數重轉那一頁就沒有筆跡（筆跡是 PDF 註解，只在記憶體拿掉、不會改到 PDF）：`render-pdf.js <pdf> <dir> 2800 16 16 clean`，再裁切。
- 講義裡老師自己做的圖（L11 的 มปร）：用 `render-pdf.js` 以 2800px 重轉那一頁，再用 `sips -c <高> <寬> --cropOffset <y> <x>` 裁切，**看過裁切結果**再用。圖＋大字的組合拆成兩張 `half` 卡：一張放圖、一張只放 `big` 大字。
- 圖片放 `public/extras/lesson-NN/`，路徑寫 `extras/lesson-NN/xxx.jpg`，長邊 960px 以內（`sips -Z 960`）。

**找網路圖片**（講義圖卡表的照片都要換成可授權的）：

```bash
bash .claude/skills/reading-lesson/scripts/find-image.sh "mango sticky rice" "Thai iced tea"
```

- 挑 CC0／CC BY／CC BY-SA，`image.credit` 寫「照片：作者 / 授權（Wikimedia Commons）」。
- 下載後**一定要看過**：要像台灣學生認得的那個東西（ชาเย็น 要橘色泰奶，不是紅茶；น้ำใบเตย 要是綠色飲料，不是一般透明飲料）。
- 補充卡（`extras`）有圖片的，課程頁一格佔一半寬（L1 老師）；有聲調表的照樣整列。
- 圖卡會裁成 4:3（`object-fit: cover`）：直式照片要先補白邊成 4:3（`sips --padToHeightWidth <高> <寬> --padColor FFFFFF`），或裁成 4:3 時保住主體，不然整杯飲料會被切掉。
- Commons 找不到貼切的就留「圖片待補」，請老師提供。老師給的圖（例如 Google 圖片網址）照用，`credit` 寫「老師指定（來源與授權待確認）」，回報時提醒公開前確認來源。

## 音檔

```bash
python3 scripts/gen-audio.py lesson-NN            # 只補沒有的
python3 scripts/gen-audio.py lesson-NN --only 詞1 詞2  # 強制重生指定的詞
```

- 預設 edge-tts，母音相關走 gTTS（規則見 `docs/audio-rerecord.md`）。
- edge-tts 回傳空音訊（NoAudioReceived）或老師說聲調不對 → 把詞加進 `scripts/gen-audio.py` 的 `FORCE_GTTS`，再用 `--only` 重生，並在 `docs/audio-rerecord.md` 加一列（出現位置、試過什麼、狀態「待確認」）。L11 的 คั้น 就是這樣處理。
- 老師說句子念太快 → 加進 `FORCE_RATE`（例 `-40%`，L14 ช่วงนี้เป็นยังไงบ้าง、ไม่ไป ฉันเหนื่อย），再用 `--only` 重生。作業字也會生成音檔（`homework` 有收）。
- L15 老師聽過要重生的例字（องุ่น、ปริมาณ、กรุณา）也是加進 `FORCE_GTTS` 再 `--only` 重生。
- edge-tts 偶爾回 503 或逾時，腳本會自動等幾秒重試（L15 之前會整個中斷）。兩個 session 同時跑 `gen-audio.py` 會互相蓋掉 `manifest.json`，跑完要確認本課的詞都在 manifest 裡，少了就再跑一次（已有的 mp3 會直接登記）。
- 單獨的「子音＋อ」音節（กอ、จอ…）edge-tts 念起來偏低、偏短，L1 聲調表 10 格與 ฎอชฎา 改 gTTS（2026-11-05）。新課的聲調表若也是單獨音節，先用 gTTS。沒有 numpy 也能粗估音高：ffmpeg 轉 16k PCM 後做自相關，看一到五聲走向（平、低降、高降、高升、降升）與長度是否一致。
- 執行環境：`gen-audio.py` 要用有裝 edge_tts／gTTS 的 `/usr/bin/python3`（Homebrew 的 python3 沒裝）。
- 兩種來源都不理想的 → 狀態改「待重錄」。如果是作業字，考慮換詞。
- 我聽不到音檔：生成完要請老師實際聽過，特別是聲調表和含 `___` 的句子。
- 修改課程字詞後，被換掉的舊音檔不再使用，回報時提一下即可，不用自己刪 manifest。

## Commit 慣例

commit 前先確認「流程」第 8 步：這一課的修正已經寫進 skill。

feat(reading): L11 母音變形：加尾音對照表、聲調表、泰式料理菜單與點餐作業
