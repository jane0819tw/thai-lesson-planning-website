# 認字課程：一課的製作與優化規格

整理自 L1–L13 的調整（2026-10-19～10-30）。目標是讓新的一課**第一版就做成老師要的樣子**，不用再逐項回頭修。

一次只做一課。每課照「流程」跑完、對過「第一版檢查清單」，交給老師看，改完再做下一課。

## 交接：下一課要帶進去的東西

做新的一課前先看這裡，做完就把用掉的項目刪掉，並把這一課要留給下一課的東西補上來。

- **L14 的 `review`**：L13 講義沒有「複習」頁，L14 沒有上一課留下的複習。做之前問老師要不要放、放什麼（例如 L13 的複合子音組合表二選一）。
- **L14 是梵文母音＋常用短句**（講義第 18–20 頁）：第 18 頁 ฤ（รึ／ริ／เรอ）、ฤๅ、ฦ、ฦๅ（後兩個「現今不使用」）與例字 ฤดู、อังกฤษ、ฤๅษี；`vowelIntro` 已有 `sanskrit` 可標本課重點。第 18 頁 12 個生活常用短句放 `practice`；第 19 頁 Q1–Q10 一問一答，現有 `qa` 只支援一題多答，十組問答要先想排法（每組一個 `qa` 群組，或新增一問一答的排法）。第 20 頁作業。
- 講義 PDF：`data/handouts/泰語認字L11-L15.pdf`（L13 第 13–17 頁，L14 第 18–20 頁，L15 第 21–26 頁）。

## 流程

1. **讀講義**：PDF 放在 `data/handouts/`（不進版本控制）。用 skill 附的腳本轉成圖片和文字，輸出放 scratchpad：
   ```bash
   osascript -l JavaScript .claude/skills/reading-lesson/scripts/render-pdf.js data/handouts/<講義>.pdf <scratchpad>/pages
   ```
   先看 `text.txt` 找出這課在哪幾頁，再用 Read 看那幾頁的 JPG。抽出的泰文常掉字，**泰文一律以頁面圖片為準**。
2. **對照講義建資料**：照下方「講義 → 課程資料」逐塊填 `data/lessons/lesson-NN.json`（形狀見 `src/types.ts` 的 `Lesson`，放進去就會出現在課程列表）。可以拿最接近的課當範本：聲調規則看 L9、清尾音看 L10、母音變形看 L11、複合子音看 L13。
3. **對過「第一版檢查清單」**。
4. **build 與看畫面**：`npm run build`（含 `tsc --noEmit`）要過。`npm run dev` 後用 Chrome 開 `/#/reading/lesson/lesson-NN` 與 `.../homework`，用 JS 捲到各區塊截圖檢查；作業頁可用 JS 讀出各題標題與題數。`resize_window` 縮不了視窗（頁面仍回報 1920 寬），手機版只能靠 CSS 判斷，回報時要說沒實測。看完關掉自己開的分頁。
5. **生成音檔**：見下方「音檔」。
6. **更新清單**：`npm run inventory` 重新產生 `docs/curriculum-inventory.md`。
7. **交給老師看**：照「回報時要講清楚」列出。不要自己把 `status` 改成 `ready`；commit 等使用者說再做。
8. **commit 前先更新這份 skill**：把這一課老師要求的修正、自己判斷之後也適用的做法，寫進對應的段落（不是只記在交接區），讓下一課第一版就照著做。skill 的修改跟課程內容放在同一個 commit，回報時列出這次補了哪些規格。

## 內容規格

### 分頁（自動依資料出現，不用設定）

順序：複習 → 母音 → 說明 → 小單元（L13-1、L13-2…）→ 尾音 → 子音 → 單字 → 練習 → 補充 → 互動練習。沒資料的分頁不會出現。捲到哪個區塊，左邊目錄那一項會變色。

- **複習**（`review`）：上一課講義上的複習練習，上課一開始先做；格式同補充卡（`title`＋`lines`）。不要放在 `extras`。
  - 一張總表一張卡，聲調表放 `toneTables`（表格本身 `title` 留空，免得和卡片標題重複）；規則句寫在表格 `note`。尾音字母**全部列出、但用小字**：放 `finals`（一個音一列，`main` 主要字母加底線、`others` 同音字母），不要用 `lines` 的大字（L13 老師覺得太大）。字母表預設收起，卡片標題右邊有「尾音字母 ▾」按鈕展開（三個分頁共用同一個開關）。有聲調表或圖片的卡會自動佔滿整列。
  - 聲調總表**不要叫「開音節」**（講義沒這個詞），照老師的說法叫「拼讀規則」（L13）：「複習：子音＋母音拼讀規則」「複習：子音＋母音＋清尾音拼讀規則」「複習：子音＋母音＋濁尾音（3 音 26 字）拼讀規則」；區塊名稱 `reviewLabel: "複習拼讀規則"`。
  - 複習有兩張以上的卡時，畫面自動變成**分頁切換**、一次看一張（老師覺得三張表上下排可讀性差）；`tab` 填分頁按鈕的短名稱（例「子音＋母音＋清尾音」）。每個分頁高度一樣、聲調表位置一樣（老師不要切換時高度跳動），這是程式自動對齊的，不用調資料。
  - 講義「上一課．複習」頁上的非練習內容（L12 的字母依發音分組總表）**放回那一課**的「補充」（`memes` 一張全寬卡，從講義裁圖），不放下一課的複習。
  - 複習裡的聲調表也會生成音檔（`gen-audio.py` 會收 `review`、`extras` 的 `toneTables`）。
  - 「哪一個拼法正確？」這類二選一題用 `choices`（`[{ options: [A, B], answer: 0|1 }]`，`lines` 留空陣列），畫面是 A／B 表格、點選顯示對錯，有「顯示答案」「重來」（L12，老師覺得純文字列點很醜）。講義上兩個都是真的字時（例 สาม／สาน），回報時請老師確認答案。
- **不要獨立的「聲調表」分頁**：聲調表放 `toneTables`，會出現在「說明」最下面；需要放在某張說明卡裡就用 `rules[].toneTable`，放在母音前就用 `vowels[].preface[].toneTable`。
- 「這是什麼意思」已改名為 **「補充」**（`memes`）。`extras` 的分頁也叫「補充」，兩個都有會同名，盡量只用一種。
- 練習只有一組時，區塊名稱自動變成那組的標題；兩組以上叫「練習・句型」。

### 說明卡 `rules`

- 規則有好幾點時，`body` 用 `\n` 分行，畫面會列點（L4、L6、L7 改過）。
- 本課重點用 `**文字**` 標示（粗體＋主色），一課一兩處就好。
- 後面的課重複前面規則時，寫「同 L6 低子音 LCp 的規則。」再列點，不要整段重抄成長段落。
- 講義把一課分成幾個小單元（「L13-1.複合子音」「L13-2.อ นำ ย」）時，每個小單元自成一個區塊，名稱照講義（`L13-1 複合子音`）：說明卡、`clusters`、練習組都填同一個 `unit`，就會排進那個區塊，不再有「說明」「練習」區塊（老師：說明底下突然出現 L13-2 不一致；多音節練習要併入對應的區塊）。區塊名稱已經寫了小單元，說明卡 `title` 留空，練習組標題就叫「多音節練習」。
- 講義只有表格、沒有說明文字時，不用硬寫說明卡，規則句放 `summary` 就好（L11）。

### 聲調表 `ToneTable`

照講義排版：

- `corner: true`：標題放表格左上角。
- `rows[].group`：最左欄子音類型（中子音／高子音／低子音 LCp／ห LCs），相鄰同 group 會合併成一格。講義把 LCp、LCs 合成一格時寫「低子音 LCp、LCs」。
- `tint: true`：短母音列淺藍、長母音列淺黃；`tint: "long"`：全部淺黃（有清尾音時一律依長母音規則，L10、L11）；`tint: "short"`：全部淺藍（有濁尾音時一律依短母音規則，L12）。
- `rows[].mark: true`：講義整列橘底的重點列（L12：低子音＋長母音是例外），表格 `note` 寫一句為什麼標橘底。
- `fill: true`：ห 補齊的那一列（黃底藍字），空字串＝空白格。
- 不發音的格子寫 `x`、`不發音`、`用ห補` 或「用…」開頭的說明，音檔腳本會自動略過。
- 多種子音一起比較時，先放本課的子音，再放對照組（L6：先 LCp 再高子音）。
- 講義的表沒標題時自己取一個短標題，說明這張表在比什麼（L11：「母音變形後的聲調（กัน／กาน）」）。
- 複習總表放在補充卡 `extras[].toneTables`，標題用「複習：…」（L9：「複習：子母音聲調規則總表」）。

### 子音、母音、尾音

- 子音卡的範例字會顯示播放鈕；子音圖示在 `data/icons.json`，優先用 Twemoji，找不到貼切的就自繪 SVG 放 `public/icons/custom-*.svg`（例：ฑ 戴金冠的舞者、ย 守門巨人、ณ 小沙彌）。
- 母音分組用 `heading`；只有短音的小卡連續標 `inRow` 排同一列；單字要放在某組母音之後就設 `vocabAfterVowel`。
- 尾音總表（「N 音 M 字」＋音節結構圖＋規則句）用 `finalsIntro`：`true`＝清尾音預設表（L10）；其他尾音課填 `{ kind: "濁", rule: "short", rows: [...] }`（L12），音數、字數自動算。
- 一個尾音的字母很多時，老師要**分組、一組一列**（L12：g ก；คฆข／p บป；พภ；ฟ／t ดตฏฎ；ทฑธฒฐถ；ซสศษ；ชฌ；จ）：`finalsIntro.rows[]` 用 `{ sound, lines: ["ก", "ค ฆ ข"] }`，尾音卡 `finals[].lines` 填同樣的分組，兩處都會一組一列顯示。分法照老師給的，不要自己合併。
- 尾音課：`finals` 每個尾音一張卡（含 `mouth` 口型說明），`vocab[].group` 對到 `finals[].group`，單字會排進對應的尾音卡，不另開「單字」分頁。
- **母音加尾音的變形**（L11 `vowelShifts`）：照講義「母音｜加尾音｜例字」左右對照。
  - `finals` 用 x 標尾音位置（`-ัx`、`เ-็x`），沒填＝講義的「/」；`changed` 標講義橘底的格子；`note` 放老師手寫的補充（例：ผม＝ผ＋โ-ะ＋ม）。
  - 一個母音有兩種寫法（เ-อ → เ-ย、เ-ิx）時**分兩列**：下一列另一邊填 `null`、本邊 `vowel` 留空字串，母音格會自動合併。
  - 例字畫面上一個一列。例字也要放進 `vocab`（音檔、中文、聽音選字都從 vocab 來）；有 `vowelShifts` 就不另開「單字」分頁。

### 複合子音 `clusters`（L13）

- 講義「C1｜C2｜組合」表：`rows` 一個 C1 一列，`group` 寫中／低／高，`tint` 照講義分色（yellow／gray／pink），講義劃掉的組合放 `crossed`（畫面加刪除線）；`c2` 合併成一格；`rules` 是右邊的規則句（音節結構圖自動畫 C1、C2）。
- 例字表放 `words`：`parts` 照講義拆法，用 `＋` 分段，母音和聲調符號用 `-` 標 อ 的位置（`คร＋-ู`、`ปร＋เ-ีย＋ว＋-้`，不要用 ◌，泰文字型會顯示成方框）；老師寫的分音節放 `＝` 後面（`＝มะ・พร้าว`）。
- 例字也要放進 `vocab`（中文、音檔、聽音選字從 vocab 來）；有 `clusters` 就不另開「單字」分頁。
- 同一課另一個小主題（L13-2 อ นำ ย）用 `rules` 說明卡＋`demo` 小卡放那幾個字（`sub` 中文、`speak` 播放）。

### 練習 `practice`

| 情況 | 設定 |
|---|---|
| 雙音節短詞、多音節練習 | `third: true`（一列三個，手機兩個） |
| 較長的多音節詞 | `half: true`（一列兩個） |
| 圖卡練習（例如泰式料理） | `images: true, third: true` ＋每個 item 的 `image`（沒圖顯示「圖片待補」） |
| 只放作業頁、不放課程頁 | `homework: true` |
| 問答（一句問、幾句回答，例 L12 天氣表達） | `qa: true`：第一個 item 是問句放左邊，其他是回答排右邊 |

- 多音節練習每個 item 都要有 `zh`。
- 標 `homework` 的練習組，在作業頁的呈現由資料決定：
  - item 有 `parts`（音節拆解）→ **短句斷句題**，會計分、跟作業一起送出（L8）。第一題加 `demo: true` 當示範。`parts` 格式：`{ syl, c, v（用 - 標子音位置，例 เ-า）, m（聲調符號，沒有就省略）, t（1–5 聲） }`。
  - 每個 item 都有 `zh`（至少 2 個）→ **聽音選中文**，不計分（L10 菜單、L11 點餐練習）。
  - 其他 → 只列出來。

### 作業 `homework`（聽寫用字）

- 放 **8 個多音節詞或短語**；講義作業頁的抄寫字放前面，不夠的從本課多音節練習補（L11 補了 ใจเย็น、สามคน、มะม่วง）。作業頁只取前 8 個。
- **不要放造句題**（L7、L9、L11 都拿掉了）。
- 講義作業頁的抄寫字就算是單音節（L13 的 ใกล้、กลัว、เปรี้ยว）也照放，回報時說明；抄寫字重複的（L13 มีความสุข 寫了兩次）拿掉，空位補本課另一個主題的詞（L13 補 อยากไปเที่ยว）。
- 挑的詞要確認音檔聽起來正確；聽起來不對的就換別的詞（L9 把 หมอดูเมาเหล้า 換成 หมอผี）。

### 作業頁第 1 題「聽音選字」（自動判斷，不用設定）

- 子音 ≥ 4 個 → 選字母；否則母音音節 ≥ 6 個 → 選音節；都沒有、單字 ≥ 4 個 → **選單字**（每次隨機 10 題）。
- 所以沒有新字母的課（聲調規則、尾音、母音變形…）至少要有 4 個 `vocab`。「互動練習」分頁也用同一個條件。

### 補充 `memes` 與圖片

- 兩張 `half: true` 的卡並排、圖片縮小；只有文字的卡設 `imageUrl: null`（沒填會顯示「圖片待補」）；只放圖可以 `title`、`desc` 留空。
- 大字泰文用 `big`；只有大字、沒圖的 half 卡會自動放大置中。
- 說明文字直接講內容，不要加「講義作業頁的推文：」這類出處前綴（L12 老師要求拿掉）。
- 講義裡的梗圖、截圖（L12 作業頁的 คิดถึงมากกก 推文）也照這個方法從講義裁出來用。大字太長會斷行，`big` 要縮短到一行放得下。
- 講義「梗圖句子／歌曲名」2×2 的圖（L13）：一張圖一張 `half` 卡，`title` 中文、`big` 泰文句子，`desc` 只寫出處（歌名、影集），不要自己加用法說明（L13 老師刪掉「มึง／กู 是很不客氣的你／我…」）。
- 講義上的圖有老師的手寫筆跡（劃線、圈字、補寫）時，用 `clean` 參數重轉那一頁就沒有筆跡（筆跡是 PDF 註解，只在記憶體拿掉、不會改到 PDF）：`render-pdf.js <pdf> <dir> 2800 16 16 clean`，再裁切。
- 講義裡老師自己做的圖（L11 的 มปร）：用 `render-pdf.js` 以 2800px 重轉那一頁，再用 `sips -c <高> <寬> --cropOffset <y> <x>` 裁切，**看過裁切結果**再用。圖＋大字的組合拆成兩張 `half` 卡：一張放圖、一張只放 `big` 大字。
- 圖片放 `public/extras/lesson-NN/`，路徑寫 `extras/lesson-NN/xxx.jpg`，長邊 960px 以內（`sips -Z 960`）。

**找網路圖片**（講義圖卡表的照片都要換成可授權的）：

```bash
bash .claude/skills/reading-lesson/scripts/find-image.sh "mango sticky rice" "Thai iced tea"
```

- 挑 CC0／CC BY／CC BY-SA，`image.credit` 寫「照片：作者 / 授權（Wikimedia Commons）」。
- 下載後**一定要看過**：要像台灣學生認得的那個東西（ชาเย็น 要橘色泰奶，不是紅茶；น้ำใบเตย 要是綠色飲料，不是一般透明飲料）。
- 圖卡會裁成 4:3（`object-fit: cover`）：直式照片要先補白邊成 4:3（`sips --padToHeightWidth <高> <寬> --padColor FFFFFF`），或裁成 4:3 時保住主體，不然整杯飲料會被切掉。
- Commons 找不到貼切的就留「圖片待補」，請老師提供。老師給的圖（例如 Google 圖片網址）照用，`credit` 寫「老師指定（來源與授權待確認）」，回報時提醒公開前確認來源。

## 音檔

```bash
python3 scripts/gen-audio.py lesson-NN            # 只補沒有的
python3 scripts/gen-audio.py lesson-NN --only 詞1 詞2  # 強制重生指定的詞
```

- 預設 edge-tts，母音相關走 gTTS（規則見 `docs/audio-rerecord.md`）。
- edge-tts 回傳空音訊（NoAudioReceived）或老師說聲調不對 → 把詞加進 `scripts/gen-audio.py` 的 `FORCE_GTTS`，再用 `--only` 重生，並在 `docs/audio-rerecord.md` 加一列（出現位置、試過什麼、狀態「待確認」）。L11 的 คั้น 就是這樣處理。
- 兩種來源都不理想的 → 狀態改「待重錄」。如果是作業字，考慮換詞。
- 我聽不到音檔：生成完要請老師實際聽過，特別是聲調表和含 `___` 的句子。
- 修改課程字詞後，被換掉的舊音檔不再使用，回報時提一下即可，不用自己刪 manifest。

## 程式改動

講義出現現有元件做不出來的版面時（L10 尾音卡、L11 母音變形表），新增元件和 `Lesson` 欄位：

- 欄位加在 `src/types.ts`，註解寫清楚每個值的意思（照現有註解的寫法）。
- 元件放 `src/components/`，在 `LessonPage.tsx` 接到對應分頁；分頁出現條件記得一起改（例如有 `vowelShifts` 就要顯示「說明」、隱藏「單字」）。
- 樣式加在 `src/styles.css` 最後，暗色模式有底色的要補 `prefers-color-scheme: dark`。
- 改完更新這份 skill。

## Commit 慣例

commit 前先確認「流程」第 8 步：這一課的修正已經寫進 skill。

課程內容與音檔分開 commit，訊息用中文，標題一句話講這課改了什麼，內文用列點：

```
feat(reading): L11 母音變形：加尾音對照表、聲調表、泰式料理菜單與點餐作業
feat(audio): 生成 L11 音檔，คั้น 改用 gTTS 並列入待確認清單
```

程式改動若影響所有課，標題寫功能本身（例：`feat(reading): 聲調表支援講義排版與分組合併`）。
