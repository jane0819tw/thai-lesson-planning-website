# 會話課程：一課的製作與優化

規劃在 `docs/conversation-plan.md`（2026-11-10 和老師定的方向：份量、單元重排、接話設計、錯字表、會話 2）。這份 skill 是**怎麼做**；規劃有變就改規劃文件，做法有變就改這裡。

一次做一課。**內容以講義為主**（2026-11-12 老師）：調整時先用講義原有的內容和圖，缺圖先裁講義的，老師之後再提供新圖。照「流程」跑完、對過「第一版檢查清單」，交給老師看，改完再做下一課。

## 已定的規格（網站）

| 項目 | 規格 |
|---|---|
| 資料 | `data/conversation/<級>/lesson-NN.json`（會話 1 ＝ `data/conversation/1/`）。形狀見下方「課程資料」 |
| 路由 | `/conversation`（列表，分級分單元）、`/conversation/<級>/lesson/<課>`（例 `/conversation/1/lesson/1`）、`.../present`、`/conversation/<級>/handout/<單元>` |
| 權限 | 每 5 課一個單位，代號 `conversation-<級>:<n>`（`conversation-1:1` ＝ 會話 1 L1–L5）。學生有權限的單元可以自由打開任一課 |
| 開關 | **拼音**（預設開）、**中文**（預設開）、**藝術字**（預設關）。網頁、投影片、列印共用同一組狀態；列印照目前的開關印 |
| 列印 | 一個單元一份 PDF，按鈕放在單元層級（列表單元最後一課後面、學生頁的單元旁邊），不放各課頁 |

注意：認字課投影片的中文**預設關**，會話課**預設開**，兩邊不要共用預設值。

## 流程（每一課）

1. **讀講義**：`data/handouts/會話Level1ver4/L<N>.pdf`（不進版本控制）。轉圖片與文字：
   ```bash
   mkdir -p <scratchpad>/conv-L<N>
   osascript -l JavaScript .claude/skills/reading-lesson/scripts/render-pdf.js "data/handouts/會話Level1ver4/L<N>.pdf" <scratchpad>/conv-L<N>
   ```
   先看 `text.txt` 抓內容，再**每一頁都用 Read 看 JPG**：抽出的泰文常掉聲調符號、掉母音（ไม่→ไม、ร้อย→รอย），**泰文一律以頁面圖片為準**。
2. **對照規劃**：看 `docs/conversation-plan.md` 這課的份量判斷、要移進／移出的句型、錯字表。移動句型照老師已定的做；老師還沒決定的，**先照講義原樣**，回報時列出建議。
3. **建資料**：照「講義 → 課程資料」填 JSON，補上講義沒有、但規格要求的部分（今日目標、對話串、接話小工具、總結）。
4. **對過「第一版檢查清單」**。
5. **build 與看畫面**：`npm run build`（含 `tsc --noEmit`）要過。`npm run dev`（port 用實際的，`lsof -nP -iTCP -sTCP:LISTEN`），用 Chrome 開課程頁、投影片，三個開關各切一次截圖；投影片每頁跑出界檢查（見 lesson-slides skill）。看完關掉自己開的分頁。Chrome 連不上要明講「沒看過畫面」。
6. **音檔**：**老師說這課定版後才生成**（2026-11-12 L3 老師：每次調整都等音檔太久）。修改期間只跑 build、看畫面、重出講義。規則同 reading-lesson 的「音檔」段；生成完請老師聽。
7. **單元最後一課做完時**：輸出單元講義 PDF，轉圖片檢查版面（同 lesson-handout skill 的檢查方式）。
8. **交給老師看**：照「回報時要講清楚」。不要自己把 `status` 改成 `ready`；commit 等使用者說。
9. **commit 前先更新這份 skill**：把老師這課的修正、之後也適用的做法寫進對應段落，和課程內容放在同一個 commit。

## 講義 → 課程資料

| 講義上的區塊 | 放到 | 備註 |
|---|---|---|
| 課名 | `title` | 照講義（或照老師定的新課名，見規劃 §3） |
| （講義沒有） | `goals` | 1–2 句「今天上完你可以…」，用學生的角度寫，例：「用泰語點一杯少糖去冰的泰奶」 |
| 上一課 | `review` | 上一課句型的快問快答 3–5 題（問句＋參考答案），L1 沒有 |
| 句型框（藍底：泰文、拼音、中文意思）＋人物 Q/A＋單字表 | `patterns[]` | 一個句型框一個 pattern。講義紅字＝`{{關鍵字}}`（畫面是深藍），底線＝`[[可替換]]`。單字表放 pattern 的 `vocab` |
| 開頭的「短句」頁 | `phrases` | ขอโทษ、ไม่เป็นไร 這類獨立短句 |
| （講義沒有） | `dialogue` | 6–8 句對話串，見「對話串」 |
| （講義沒有） | `toolbox` | 這課的接話小工具 1–2 個，清單見規劃 §5.3 |
| 練習頁 | `practice[]` | 見「練習」 |
| 補充頁（文化、梗、歌詞、影片連結） | `extras[]` | 不加「有時間再上」標籤（L2 老師移除） |
| 人稱表、挑食表這類大表 | `extras[]` 的 `table` | 不放在句型裡 |
| （講義沒有） | `recap` | 句型總結（**可省略**）：每個句型一行（問句／回答），對 `goals`。這課已經有 `template` 把句型串起來（例：L1 自我介紹）就不放，避免重複（L1 老師） |

### 課程資料（實際形狀見 `src/conversation/types.ts`，範本是 `data/conversation/1/lesson-01.json`）

- `blocks` 照講義順序排：`phrases`（短句卡）、`pattern`（句型：`th/rom/zh` 是藍底句型框、`frame` 公式、`examples` 人物 Q/A、`vocab` 單字（不寫單字標題，L1 老師：「國家、地區」不要寫出來）、`toolbox` 接話小工具）、`template`（直排的順序，例：自我介紹的六句）。
- 例句 `who`：`f` 女、`m` 男（頭像）。問句女生用 `คะ ká`、陳述用 `ค่ะ kâ`。
- 問句加 `q: true`：每個問句開新的一列放**左邊**，後面的回答放這列**右邊**（一個問句可以有好幾個回答，直排）；列與列之間虛線分開（L1 老師）。講義是「兩人各問一次」時（L1 ชื่อ），照「問、答、問、答」排。
- 模板裡的 `[名字]`、`[國家]` 這類中文空格，發音時會自動拿掉（`plain()`）。
- `dialogue.lines[]`：`who`（名字）、`avatar`（emoji）、`segs[]`（一則訊息分好幾段，每段一個 `tag`）。
- `tag`：`answer` 回答、`add` 補一句、`ask` 反問、`react` 接話詞。店員、老闆的新用語不標標籤（L2 老師：不需要「聽懂就好」，`listen` 不再使用）。
- `star: true`＝★必學；沒標的是「認得就好」。**畫面、講義都不顯示記號**（不加星星、不加邊框，L1 老師），`star` 只用來算份量、給老師參考。
- 拼音、泰文、中文裡的 `{{ }}`、`[[ ]]` 位置一一對應。
- 補充的表格 `table.rows`：一格裡一行一個詞（`\n`），每個詞寫「泰文｜拼音｜中文」，拼音、中文會跟著開關。
- 補充的影片：老師給的 YouTube 片段用 `video: { id, start, end, label }` **直接嵌入播放器**（只播那一段；列印印網址），L1 達人秀 5–15 秒（`end` 比講到的最後一個字多留 2 秒，L1 老師）。影片下面自動有速度拉桿（0.25×–1.5×，`YouTubeClip` 用 postMessage 調 `setPlaybackRate`，開始播放時再套一次）。沒有指定片段的才用 `link`。
- 單字有講義的圖時寫 `image`（取代 `icon`）；練習卡的照片也是 `image`。單字卡的圖 3.4rem（L2 起食物照片多，2.2rem 看不清楚）。
- 補充卡可以放講義的圖：`images: [...]`（一排，畫面最高 220px、列印 140px），例：L2 奶茶分不清、L4 香蕉＝easy、L5 餐桌四寶。
- 練習卡的照片預設裁成 3:4 直式；橫的組合圖（L5 Lisa＋AWESOME、榴槤＋捏鼻子）自動整張顯示（`data-wide`）。
- 數字（L3 0–10，L4 100 以上）用 `phrases`：0–10 的 `icon` 寫阿拉伯數字、`zh` 留空（L3 老師：不要出現 ๓ 這種泰文數字）；大數字 `icon` 放不下就不放，數字寫在 `zh`。要指定每列幾張時寫 `rows`（L3 老師：0–10 用 `[5, 6]`，1–5 一列、6–0 一列）。
- 講義是格子表的數字（L3 11–99：橫軸個位、直軸十位、留「?」給學生想）照講義用 `numtable`（L3 老師：不要拆成一張張卡）：`rules` 寫規則（尾數 1 說 เอ็ด、二十說 ยี่），格子寫「泰文｜拼音」、關鍵字 `{{ }}`，`"?"` 是空格題、`""` 留白，點格子播放；`collect_conv` 會收格子的音檔。
- 同一個句型講義分好幾頁（L2 อยากซื้อ＋描述：甜度冰塊一頁、辣度大小一頁；L5 เป็นยังไง：人、味道、天氣）就照頁分成幾個 pattern，`zh` 後面括號註明這頁的主題。「程度」表（ไม่／นิดหน่อย／มาก／จังเลย）當成問句後面的四個回答。
- 例句的拼音、泰文（連同喇叭）在投影片不換行，問、答兩欄依內容分寬度，放不下整頁縮小（L3 老師：gèe gâew 被擠到下一行）。
- 單字卡的中文在投影片不換行（L3 老師：「個（包包、帽子…）」換行後那張卡比別張低）。
- 單字卡、補充的中文只寫意思，不加括號補充說明（L2 老師拿掉「（橘色）」「（單一尺寸）」「唸 สะ-หละ」這類）。
- 講義的單字表只有泰文、拼音沒有中文時（L2 食物、L4 相關食物）自己補中文，回報時列出來。
- 「多少錢」這類價錢句型不要用 `[價格]` 空格，寫具體的數字（[[ห้าสิบ]]บาท），學生才聽得到完整的句子。

## 內容規格

### 份量

- 一課 **2–3 個核心句型**、★必學單字 **12–18 個**（這是規劃時參考 50 分鐘初級會話訂的，不是老師定的；老師習慣講義一課約 4 個句型，L3 老師加到 4 個，以老師為準）。講義超過時，不刪內容：多的句型照規劃移課（老師已定的），多的單字不標 ★。回報時列出每課的句型數、★字數。

### 拼音

- 拼音依聲調上色（`Rom`），關鍵字（`{{ }}`）整段深藍。
- 拼音大小接近泰文、小一號（L2 老師：有些學生只看拼音，太小怪怪的，但太大會擠版面）：一般句子泰文 1.3rem／拼音 1.15rem，單字卡 1.15／1rem，句型框 1.6／1.35rem，講義 1.15／1rem。
- **說明文字裡的泰文都要附拼音**（L1 老師）：今日目標、模板說明、練習題目、練習卡、補充說明寫 `<<泰文|拼音>>`，顯示成「泰文（拼音）」，拼音跟著開關。
- 照講義的寫法（thai2english 系統：`dtâi-wăn`、`bpai`、`kŏr`、`chôp`），不換系統。
- 講義的 chăn 常夾隱形字元（`c​hăn`、`c﻿hăn`），寫進 JSON 前清掉：`text.replace(/[​﻿]/g, '')`。
- 拼音錯字照規劃 §6 改，新發現的也記進 §6。

### 今日目標與總結

- `goals` 和 `recap`（或 `template`）要對得起來：目標說「點一杯少糖泰奶」，總結就要有那個句型。
- `recap` 可有可無：有 `template` 串起全部句型的課不放（L1 拿掉，和自我介紹重複）；沒有模板、句型多的課（例：L2 飲料店）才放。
- 投影片第一頁是封面＋今日目標；有 `recap` 時最後一頁是總結。

### 對話串

- 6–8 句，只用**到這課為止**教過的句型和字，**要結合前面幾課**（L3 老師：L3 對話串加上 L1 問國家、名字、แล้วคุณล่ะ，L2 喜歡喝什麼、少糖、ฉันก็）；需要新的店員用語時可以用，但不加標籤。
- 對話框左右兩欄交錯、上下重疊（L1 老師：一則在下面一則才開始，框框太小）：換人說話時下一則和上一則重疊約三分之二，同一人連說才完全往下（`DialogueCard` 的 `SPAN`）；而且**不能早於同一欄上一則的結尾**（L1 第 9 頁 Tae、Jane、Tae 三則，第二則 Tae 疊到第一則 Tae 上）。列印仍是劇本格式。
- 模板（`template`，例：自我介紹）投影片、課程頁、列印都分左右兩欄：前一半在左、後一半在右，中間一條直線（L1 老師：一欄太浪費空間）。只有手機寬度（≤640px）才變回一欄。
- 身份卡（沒有照片的練習卡）列印時一排 5 張、圖示縮小（L1 老師：省下的空間讓補充擠進同一頁）。有照片的看圖卡不變。
- 投影片分頁：在要開新頁的那則訊息加 `newSlide: true`（有任何一則設了就全照手動分頁）。L1 老師要「Jane 三段＋Tae 三段」放同一頁。
- 學生可以換成自己資料的地方（名字、國家、喜歡的東西、點的東西）用 `[[ ]]` 畫底線：老師口頭帶「換成自己」時就是換這些。
- 對話串**不放**「一對一練法」說明（跟讀→分角色→換成自己由老師口頭帶，L1 老師移除）；第一頁只放「接話三步驟」。
- 這課教數字、價錢的，對話串要用到這課新的範圍（L3 老師：要有 10 以上的數字），不要只用前一課就會的。
- 至少有一次「回答＋補充＋反問」三步驟、至少用一個這課的接話小工具。
- 情境用講義這課的主題（L2 飲料店、L4 夜市殺價、L7 麵店）。
- 句子自己寫的，回報時列出來請老師改。

### 接話小工具

- 照規劃 §5.3 的清單，每課 1–2 個，放在第一個用得到它的句型旁邊。之後的課可以重複用、不重複教。投影片上小工具**自己一頁**（只放小工具，不放句型框，L2 老師），接在那個句型頁後面（L2 老師：放在句型頁會讓那頁變高、縮得比其他句型頁小，格式不統一）；課程頁、講義仍放在句型卡最下面。

### 練習

| `kind` | 用在 | 例 |
|---|---|---|
| `roleplay` | 角色扮演（講義 L4、L7） | 老師當老闆娘，學生問價、殺價、完成購買 |
| `qa` | 兩人互問、三來回規則 | 「你喜歡吃什麼？」至少來回 3 次 |
| `picture` | 看圖說話（講義 L1 看圖介紹） | 用講義的照片（裁下來放 `image`） |
| `translate` | 講義的「中翻泰」句子 | 保留，但每課至少要有一個 `roleplay` 或 `qa` |

- **學生大多一對一**（L1 老師）：一課練習 **2 個**就好，寫成老師和學生兩個人做的（不要「兩人一組」、「每人抽卡」）。L1：看圖介紹＋新朋友身份卡（老師抽卡當新朋友、學生用自己身份，再交換）。不另開一個 `qa`。**練習卡不放「可以用的句子」（`hints`）、不放例句、不寫長的規則說明**（L1 老師）：`body` 只寫一句題目（看圖介紹：「用 ชื่อ、มาจาก、เป็นคน、ชอบ 介紹這三個人。」），角色扮演的規則老師口頭講，`body` 可以省略。
- 講義的練習照收；練習只有 `translate` 的課，自己補一個角色扮演，回報時說明。
- 練習的圖片要配得上題目（講義 L5 p9 圖片是 เป็นยังไง、題目是問地點，對不上）。

### 投影片與講義（L1 定的）

- 句型頁版面（L1 老師）：左邊藍底句型框（**不放公式小字**，`frame` 欄位已拿掉），右邊一問一答（問左答右、虛線分列），單字排在下面一整排、接話小工具最下面（投影片另一頁，見「接話小工具」）。
- 列印時句型的例句會斷行（問、答並排太擠，L3 กี่）就在 pattern 加 `printStack: true`：問、答一句一列、不斷行。
- 句型頁要讓老師指著圖問學生時（L3 ใช่ไหม），在 pattern 加 `quiz`：一排只有圖、不寫字，放前面學過的單字；圖固定 130px 置中（列印 80px），L3 老師：撐滿整排太大。同一個句型有單字又有 `quiz` 時，兩者自動排在同一列（L3 老師：บาท 和價格圖）。圖上不能有字（L3 冬蔭功圖上的 Tom Yum Kung、鼻通圖上的中文會洩漏答案，換掉了）。
- 句型的單字分好幾類時（L2 甜度／冰塊、辣度／大小）用 `vocabRows`（一排一類），句型改成**左右排**：左邊句型框＋句子直排、右邊單字（L2 老師）。每一類至少配一句例句（L2：少糖一句、少冰一句；M 號一句、不辣一句）。講義的對照圖放 pattern 的 `images`：投影片自己一頁、接在句型頁後面（L2 老師），課程頁和講義放在左欄句子下面。講義 A4 太窄，列印時改成上下排。
- 單字卡：圖示（國旗）在第一列，下面泰文＋喇叭、拼音、中文置中，卡片窄（最小 118px），所有單字卡外觀一樣（★必學不另外標示）。喇叭在卡片右上角（不跟泰文同一行，否則泰文會偏左）。
- 開關有四個：拼音、中文、**喇叭**（播放鈕，預設開）、藝術字。拼音隱藏用 `visibility: hidden`（課程頁、講義）：關掉拼音時中文不會跑上來（L1 老師）。**中文關掉就整行拿掉、不留空白**（`display: none`，L2 老師；中文在最下面，不會讓別的行跑位）。**例外：投影片關掉拼音時整行拿掉、不留空白**（`.c-slides.c-hide-rom .c-rom{display:none}`，L1 老師），投影片會重新縮放、字變大；中文、喇叭在投影片仍保留位置。投影片快捷鍵 S＝喇叭。
- 關鍵字（`{{ }}`）用深藍粗體（`--ck: #2a5d8f`，和句型框同色）。L1 老師試過紅色 #dc2626、珊瑚紅 #e0654f 都覺得太紅，從深藍／螢光筆／橘三種預覽裡選了深藍。
- 快問快答（`review`）分左右兩欄：前一半左、後一半右，中間虛線（L2 老師）。
- 投影片：封面＋今日目標一頁 → 複習 → 每個 block 一頁（有 `images` 的句型後面多一頁圖、有接話小工具的再多一頁小工具）→ 對話串（一頁最多 4 段話，一則訊息不拆開，`SEGS_PER_SLIDE`）→ 每個練習一頁 → 每張補充一頁 →（有 `recap` 才有）總結。整段對話放一頁會縮到 0.3 倍看不清楚。
- 快捷鍵：← → 換頁、R 拼音、Z 中文、S 喇叭、A 藝術字、P 筆、N 補充、F 全螢幕、Esc 離開。
- 講義：每課另起一頁；句型之間用實線分開（句型內的問答列是虛線，之間用實線才分得出層次）、句型區塊不畫卡片外框（L2 老師）；單字卡、看圖卡、句子不讓最後一行只剩一個音節／一個字（`text-wrap: balance`，看圖卡說明不換行，L2 老師：chaa nom kài｜múk、象｜牌啤酒）；有 `joinNext` 的課補充改兩欄：合併的兩張各 50%、其他 100%（L2 老師），沒有的課維持一排三張；個別補充要在講義佔整排寫 `wide: true`（L1 達人秀）；單字 7 個以內排成一列（L2 老師：第二列只剩一個字浪費空間）；補充卡一排三張、同一排的框等高（L3 老師）、圖最高 64px、有表格的佔整排；看圖卡照片在左、名字和說明在右（照片 72px，橫的組合圖 120px）——L2 老師要練習和補充在同一頁；有照片的看圖卡列印時排成一排（L2 四張不會掉一張到下一排）；補充的單字列印時一排三個（L4 其他幣值、L5 餐桌四寶直排會佔半頁）；列印時卡片不用 grid（grid 裡放不下的卡會整張推到下一頁、留一大片空白）；句型的單字表排在例句下面 4 欄、例句 2 欄；對話串印成劇本格式（說話的人在左、同一則訊息的幾段橫排）。L1 印出來 10 頁（封面＋9 頁）。單元一（L1–L5）37 頁。

### 補充

- 文化補充、歌詞賞析、影片連結（YouTube 用 `link`，不嵌入第三方影片片段）都放 `extras`，不加「有時間再上」標籤。投影片一張補充一頁；講義的補充是好幾格的表（L3 泰文數字知多少：555｜๙｜ผี）就照格子拆成幾張，連續寫 `joinNext` 並排成一頁（三張以上自動置中、圖同高），不加標題（`title` 可省略）、說明放 `footnote`；講義在圖的位置放大字的（๙、ผี）寫 `bigText`。內容少的兩張可以合併：前一張寫 `joinNext: true`，左右兩塊、中間虛線（L2：奶茶分不清＋เกมชาเย็น、ไม่ใส่สี＋1 ศูนย์ 2 ต่ำ）。合併的兩張要上下對齊：標題、圖、單字的順序一樣，多的說明放 `footnote`（顯示在最下面），不要放 `body`（L2 老師：手標泰奶健康系列的說明移到最下面，和左邊的圖對齊）。補充的例句（`lines`）橫排靠左、間距固定（L2 老師：三種奶茶橫向，但名稱不要拉太開）。講義上的影片截圖也要裁下來用（L2 เกมชาเย็น、L3 數字歌），放在那張補充卡（有 `link` 的照樣留連結）。
- 歌曲已經在網站「歌詞」做成頁面的，`link` 指向站內頁。
