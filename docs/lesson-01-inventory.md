# 第 1 課：中輩子音入門＋四個基本母音

認識 8 個子音（6 個中輩＋น ม 兩個鼻音）與 า ิ ี ู 四個母音，用 16 個單字拼出第一批簡單句。

## 規則認知
- **泰文字母有「頭」**：多數泰文字母從「頭」（圓圈或彎鉤）開始書寫，認字時先找頭，再看身體往哪個方向延伸。
- **母音有固定位置**：母音依附在子音旁：า 寫在子音右邊；ิ ี 寫在子音上方；ู 寫在子音下方。本課母音都以 อ 當示範子音（อา อิ อี อู）。
- **長短母音**：า ี ู 是長音（拖長一點），ิ 是短音（短促）。長短不同，單字就不同。
- **尾音的收法**：ก 結尾收 k；ด 結尾收 t；บ ป 結尾收 p；น ม 結尾收 n / m。尾音收 k t p 的短促音節，聲調會變低（例：ปิด bpìt、กบ gòp）。

## 例句（11）
| 泰文 | 拼音 | 中文 |
|---|---|---|
| อา มา | aa maa | 叔叔來了。 |
| ตา มา ดู | dtaa maa duu | 外公來看。 |
| กา บิน | gaa bin | 烏鴉飛。 |
| ตา ดู กบ | dtaa duu gòp | 外公看青蛙。 |
| กบ ปิด ตา | gòp bpìt dtaa | 青蛙閉上眼睛。 |
| อา กิน ปู | aa gin bpuu | 叔叔吃螃蟹。 |
| อา มี ปู | aa mii bpuu | 叔叔有螃蟹。 |
| ตา ดี | dtaa dii | 眼睛很好（視力好）。 |
| นา ดี | naa dii | 稻田很好。 |
| อา ปา ดิน | aa bpaa din | 叔叔丟土。 |
| กิน ดิน | gin din | 吃土。（也是「窮到吃土」的玩笑話） |

## 梗圖
- กินดิน（吃土）：窮到月底只能吃土 → 搭配句子 s11，畫一個空空的碗或口袋的角色圖。
- 圖說：月底的我：กินดิน
