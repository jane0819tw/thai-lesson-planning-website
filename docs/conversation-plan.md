## 1. 網站上的會話課程（規格）

和認字課程同一套做法：

| 項目 | 規格 |
|---|---|
| 入口 | 首頁「會話」分類開放（`src/categories.ts` 的 `conversation` 加 `to`），列表 `/conversation` |
| 開放權限 | **每 5 課一個單位**，同認字課。代號 `conversation-1:<n>`（會話 1 的第 n 單元：`conversation-1:1` ＝ L1–L5）。會話 2 用 `conversation-2:<n>`。後端 `Courses.gs` 的格式檢查已經允許，不用改 |
| 一課的頁面 | `/conversation/1/lesson/1`：今日目標 → 句型 → 對話串 → 練習 → 補充 → 句型總結 |
| 投影片模式 | `/conversation/1/lesson/1/present`，一個句型一頁、對話串一頁、練習一頁 |
| 列印 PDF | **單元層級**一份（L1–L5 一份），列印按鈕放在單元最後一課後面、學生「我的課程與作業」的單元旁邊，同認字課 |
| 自由開啟 | 學生有權限的單元可以自由打開任一課，不用照順序 |
| 顯示開關 | **拼音**（預設開）、**中文**（預設開）、**藝術字**（預設關）。網頁、投影片、列印都吃同一組開關；列印照目前的開關狀態印 |

| L20 複習 | FreeTalk＋พี่น้อง、เวลา…ก็จะ、ว่า | 很好 | |

### 2.2 整體問題

1. **同主題分散**：時間（L12、L15、L16 中間隔了顏色和地點）、方向位置（L5、L14）、量詞（L3、L7、L11，可以保留三層，但要設計成逐層加深）。
2. **只有單元二、四有複習課**（L10、L20），單元一、三沒有。
3. **句型密度不平均**：L5、L12、L15、L18 明顯比其他課重。
4. **只有一問一答**：學生回答完就斷了，沒練到「接下去聊」。
5. **練習都在最後一頁**：前面約 7 頁輸入，最後才 1 頁練習，學生開口時間不夠。

### 2.3 要保留的優點

- 紅字標關鍵字、底線標可替換的位置、人物頭像做 Q/A。
- L4 殺價表格、L7 點餐角色扮演、L14「走到想前往的地方」這類任務型練習。
- 歌詞賞析、影片片段（金孫爆富、泰劇預告、สสส 廣告）、文化補充（奶茶分不清、香蕉＝簡單、餐桌四寶、幸運色）。
- L10、L20 的 FreeTalk（L20 Freen／Becky 對話可當期末範本）。

| 一 | 生存入門 | L1 自我介紹 → L2 喜好與點飲料 → L3 數字與量詞 → L4 價錢與殺價 → L5 地點方向與「怎麼樣」＋最後 15 分鐘「曼谷一日」複習任務 |
| 二 | 吃飯與移動 | L6 語言與感受 → L7 點餐 → L8 加醬料與付款 → L9 交通方式 → L10 複習與生活（維持） |
| 三 | 逛街與城市 | L11 購物與單位 → L12 顏色（原 L13）→ L13 比較與最高級（原 L18＋原 L19 的 ที่สุด）→ L14 地點與位置（原 L14 改標題，小心講的字放補充）→ L15 複習：逛 IconSiam 任務 |

### 3.1 移動的句型

| 句型 | 原本 | 移到 | 理由 |
|---|---|---|---|
| 人稱大表 | L1 | L1 補充 | 只教 ผม／ฉัน／คุณ／เขา／พี่／น้อง |
| ราคา、เท่าไหร่、แพง、ถูก | L3 | L4 | L4 變成完整的「價錢與殺價」 |
| 大數字第二排（千萬以上） | L4 | 刪或補充 | 購物用到 10 萬就夠 |
| มี | L4 | 單元二或三 | 和殺價無關。**目的地還沒定，網站 L4 暫時保留**（L4 練習的 LingLing／Orm 也用到 มี），定了再搬 |
| ยัง（了沒） | L5 | L9 和 เคย…แล้ว 一起 | 都是「做過了沒」。網站 L5 已拿掉；做 L9 時把講義 L5 p2（句型＋มีแฟน／ซื้อของ／ลองชิม／แต่งงาน／กลับบ้าน）和 p9 練習（Poon 買東西了、PopeBella 還沒結婚）一起搬過去 |
| ที่สุด、มากที่สุด | L19 | 新 L13 | 比較級、最高級一起教 |
| ดีกว่า／ละกัน／ก็ได้（做決定） | L18 | 新 L15 複習或 L20 | L20 對話已用到「去哪裡都可以」 |
| ทำไม／เพราะว่า | L19 | 新 L19 健康 | 「為什麼沒來？因為頭痛」 |
| ถ้า…ก็จะ、เวลา…ก็จะ | L17、L20 | 放在一起 | 句型相近 |
| ว่า 轉述（ถาม／บอก／ตอบ） | L20 | 會話 2 | |
| ช่วย…หน่อย | L19 | 新 L19 或 L6（หน่อย 那課） | |

## 5. 「接下去聊」的設計

### 5.1 接話三步驟（整套課程共用，寫在 L1）

> ① 回答問題　② 多補一句　③ 把問題丟回去

L1 範例：

| | 泰文 | 拼音 | 中文 | 步驟 |
|---|---|---|---|---|
| A | คุณชื่ออะไรคะ | kun chêu à-rai ká | 你叫什麼名字？ | |
| B | ฉันชื่อ Jane ค่ะ | chăn chêu Jane kâ | 我叫 Jane。 | ①回答 |
| | มาจากไต้หวัน | maa jàak dtâi-wăn | 來自台灣。 | ②補一句 |
| | แล้วคุณล่ะ | láew kun lâ | 那你呢？ | ③反問 |
| A | ผมชื่อ Tae ครับ เป็นคนไทย | pŏm chêu Tae kráp, bpen kon tai | 我叫 Tae，是泰國人。 | ①② |
| | คุณชอบอะไรครับ | kun chôp à-rai kráp | 你喜歡什麼？ | ③換話題 |

### 5.2 對話串（每課一頁）

6–8 句、LINE 對話框樣式，每句標「回答／補充／反問／接話詞」，可替換的地方畫底線。只用到這課為止教過的句型；需要新的聽力用語（例 รับอะไรดีคะ）時標「聽懂就好」。

L2 範例（飲料店）：

| | 泰文 | 拼音 | 中文 | 標籤 |
|---|---|---|---|---|
| 店員 | สวัสดีค่ะ รับอะไรดีคะ | sà-wàt-dee kâ, ráp à-rai dee ká | 歡迎光臨，要點什麼？ | 聽懂就好 |
| 客人 | อยากซื้อชาเย็นค่ะ | yàak séu chaa yen kâ | 我想買泰奶。 | 回答 |
| 店員 | หวานปกติไหมคะ | wăan bpòk-gà-dtì măi ká | 正常甜嗎？ | |
| 客人 | หวานน้อยค่ะ ไม่ใส่น้ำแข็ง | wăan nói kâ, mâi sài náam kăeng | 少糖，不加冰。 | 補充 |
| 店員 | ได้ค่ะ | dâai kâ | 好的。 | |
| 客人 | พี่ชอบดื่มอะไรคะ | pêe chôp dèum à-rai ká | 姊姊喜歡喝什麼？ | 反問 |
| 店員 | ชาเขียวค่ะ แล้วน้องล่ะ | chaa kĭieow kâ, láew nóng lâ | 綠茶，那妳呢？ | |
| 客人 | ฉันก็ชอบชาเขียวค่ะ | chăn gôr chôp chaa kĭieow kâ | 我也喜歡綠茶。 | 接話詞 |

### 5.3 接話小工具（每課 1–2 個，固定放在句型頁角落）

| 單元 | 接話小工具 |
|---|---|
| 一 | แล้วคุณล่ะ 那你呢（L1）、ฉันก็… 我也…（L2）、อ๋อ ŏr 喔～原來如此、จริงเหรอ jing rĕr 真的嗎？ |
| 二 | อะไรนะ 什麼？（L6）、พูดช้า ๆ หน่อย 說慢一點（L6）、ฉันก็เหมือนกัน 我也是、แล้วแต่ 看情況（L8）、จริงหรือเปล่า 是不是真的（L10） |
| 三 | ดีจัง 真好、น่าสนใจ nâa sŏn jai 好有趣、เช่น… chên 例如… |
| 四 | ทำไมล่ะ 為什麼呢、งั้น… ngán 那麼…、ก็ได้ 也行、เพราะว่า 因為 |

### 5.4 追問樹

中間一個問題，四周是到目前為止學過的疑問詞：อะไร（L1）、ที่ไหน／ยังไง（L5）、กับใคร（L9）、เมื่อไหร่（L12→新 L16）、ทำไม（L19）。每到新單元多一個方向可以追問。

### 5.5 練習規則

- **三來回規則**：每題至少來回 3 次才換題。
- **接話計分**：用一個接話小工具得 1 分（複習課用）。
- **老師只答一半**：學生必須追問。

## 7. 會話 2 建議

### 7.1 會話 1 已教、會話 2 可以直接用

เคย、จะ、แล้ว、ยัง、กว่า、ที่สุด、ถ้า…ก็จะ、ทำไม／เพราะว่า、ว่า、時間與日期、數字與量詞。

### 7.2 會話 2 要補的

- **文法**：กำลัง／อยู่（正在）、ต้อง／ควร／อาจจะ（必須、應該、可能）、ให้（讓、給）、โดน／ถูก（被）、ก่อน／หลังจาก（之前、之後）、動詞＋ไป／มา、語氣詞 นะ／สิ／เลย／จัง／อะ。
- **情境**：職業、家人、天氣季節、訂房入住、藥局看醫生、邀約與拒絕、LINE 與電話。

### 7.3 單元規劃

| 單元 | 主題 | 各課 | 新文法 |
|---|---|---|---|
| 一 | 人與日常 | 家人與職業、一天的作息、興趣與能力、天氣季節、複習 | กำลัง、ก่อน／หลังจาก、เป็น／ได้／ไหว |
| 二 | 旅行實戰 | 訂房入住與抱怨、按摩 SPA、藥局看醫生、Grab 與包車、複習 | ต้อง、อย่า、ให้ |
| 三 | 交朋友 | 邀約與拒絕、LINE 與電話、送禮與節日、給建議、複習 | ว่างไหม、ควร、น่าจะ |
| 四 | 說故事 | 講經驗、倒楣事、心情與語氣詞、計畫與夢想、期末任務（用泰語介紹台灣或一趟旅行） | ตอนที่、หลังจากที่、โดน／ถูก、語氣詞 |

會話 2 沿用會話 1 的格式（今日目標、2–3 句型、對話串、接話小工具、任務、文化補充），接話小工具從會話 1 的清單繼續累積。
