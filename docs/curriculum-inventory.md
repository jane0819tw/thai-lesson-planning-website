# 泰文認字課程內容清單

## L1 中子音（9 個）

認識 9 個中子音與 5 個聲調；先學中子音加長母音 อ 的聲調規則。

| 字 | 名稱 | 拼音 | 意思 | 發音 | 同音高子音 |
|---|---|---|---|---|---|
| ก | กอ ไก่ | gor gài | 雞 | g |  |
| จ | จอ จาน | jor jaan | 盤子 | j |  |
| อ | ออ อ่าง | or àang | 盆 | / |  |
| ป | ปอ ปลา | bpor bplaa | 魚 | bp |  |
| บ | บอ ใบไม้ | bor bai mái | 樹葉 | b |  |
| ต | ตอ เต่า | dtor dtào | 烏龜 | dt |  |
| ด | ดอ เด็ก | dor dèk | 小朋友 | d |  |
| ฏ | ฏอ ปฏัก | dtor bpà-dtàk | 刺棍 | dt |  |
| ฎ | ฎอ ชฎา | dor chá-daa | 舞冠 | d |  |


單字：ต่อ 接續、อ๋อ 喔

作業：ก、จ、อ、ป、บ、ต、ด、ฏ、ฎ、ต่อ、อ๋อ

## L2 單母音（一）4 組

母音種類與位置；學 /a/ /i/ /u/ /e/ 四組長短音，並練習中子音的聲調規則。

- 母音 /a/：-ะ / -า　例字：จะ 將要、อะ 啊、ตา 眼睛、บ้า 瘋子
- 母音 /i/：-ิ / -ี　例字：ดิ 語助詞、กะปิ 蝦醬、ดี 好、กี่ 多少
- 母音 /u/：-ุ / -ู　例字：ดุ 兇猛、กู 我（粗俗）、ปู่ 阿公
- 母音 /e/：เ-ะ / เ-　例字：เตะ 踢、เอะอะ 喧嘩、เจ 齋、เจ๊ 姊

單字：อี 罵人前綴、จู๋ 丁丁、ป้า 阿姨、ปี 年、ปู 螃蟹、ตี 打、บี๋ 親愛的

作業：กี่ปี、เจ๊、ดุ、กะปิ、บ้า、เตะ、ดู、อา

## L3 單母音（二）5 組

學 /ae/ /o/ /or/ /uh/ /eu/ 五組長短音，並複習 L2 的長短音辨認。

- 母音 /ae/：แ-ะ / แ-　例字：แตะ 碰、แกะ 羊、แก 你、แต่ 但是
- 母音 /o/：โ-ะ / โ-　例字：โต๊ะ 桌、โต 大、長大
- 母音 /or/：เ-าะ / -อ　例字：เกาะ 島、ต่อ 接續
- 母音 /uh/：เ-อะ / เ-อ　例字：เจอ 見
- 母音 /eu/：-ึ / -ือ　例字：อึ 屎、ดื้อ 頑皮

單字：เออ Yes、เบอร์ 號碼、แก่ 老、แก้ 解決、ปีโป้、โก๋แก่ 花生品牌

作業：โต๊ะ、ตาโต、เจอ、ดื้อ、อึ、แต่、แกะ、เกาะ

學 11 個高子音；高子音加長母音不加符號時發第五聲。

|---|---|---|---|---|---|
| ผ | ผอ ผึ้ง | pŏr pêung | 蜜蜂 | p |  |

| ถ | ถอ ถุง | tŏr tŭng | 袋子 | t |  |
| ฐ | ฐอ ฐาน | tŏr tăan | 壇 | t |  |
| ห | หอ หีบ | hŏr hèep | 箱子 | h |  |
| ข | ขอ ไข่ | kŏr kài | 蛋 | k |  |
| ฃ | ฃอ ฃวด | kŏr kûuat | 瓶罐 | k |  |
| ฉ | ฉอ ฉิ่ง | chŏr chìng | 小鈸 | ch |  |

## L5 複合母音、特殊母音

學複合母音 /ia/ /eua/ /ua/，以及只有短音的特殊母音 -ำ ไ- ใ- เ-า。

- 母音 /ia/：เ-ียะ / เ-ีย　例字：เผียะ 拍打聲、เสีย 壞了、เตี้ย 矮
- 母音 /eua/：เ-ือะ / เ-ือ　例字：เสือ 虎、เบื่อ 無聊
- 母音 /ua/：-ัวะ / -ัว　例字：หัว 頭、ตัว 件
- 母音 /am/：-ำ / —　例字：จำ 記得、ดำ 黑、ฉ่ำ 多汁
- 母音 /ai/：ไ- / —　例字：ได้ 可以、ไข่ 蛋、ไก่ 雞、ไป 去
- 母音 /ai/：ใ- / —　例字：ใส่ 放入、ให้ 讓、ใจ 心
- 母音 /ao/：เ-า / —　例字：เอา 要、เข้า 進入、เก้า 9

單字：เหี้ย 澤巨蜥；damn!、เสื้อผ้า 衣服、ผัว 老公、ถั่ว 豆

作業：เข้าใจ、จำได้、เอา、ไปเกาะ、เสื้อผ้า、เบื่อ、หัวใจ、เสียใจ、เก้า

## L6 低子音 LCp（一）7 個

低子音 LCp 有同音的高子音；用來補齊高子音沒有的聲調。本課學 พ ภ ฟ ท ฑ ธ ฒ。

| 字 | 名稱 | 拼音 | 意思 | 發音 | 同音高子音 |
|---|---|---|---|---|---|
| พ | พอ พาน | por paan | 高腳盤 | p | ผ |
| ภ | ภอ สำเภา | por săm-pao | 帆船 | p | ผ |
| ฟ | ฟอ ฟัน | for fan | 牙齒 | f | ฝ |
| ท | ทอ ทหาร | tor tá-hăan | 軍人 | t | ถ, ฐ |
| ฑ | ฑอ มณโฑ | tor mon-toh | 神話中的巨人之妻 | t | ถ, ฐ |
| ธ | ธอ ธง | tor tong | 旗子 | t | ถ, ฐ |
| ฒ | ฒอ ผู้เฒ่า | tor pôo tâo | 老人 | t | ถ, ฐ |


作業：พ、ภ、ฟ、ท、ฑ、ธ、ฒ、สีฟ้า、ทำให้、เธอ、พอใจ、ภาษา

## L8 低子音 LCs（10 個）

LCs（single）沒有同音的高子音，缺少的聲調改用 ห 補齊。本課學 ม น ย ว ง ล ร ณ ญ ฬ。

|---|---|---|---|---|---|
| ม | มอ ม้า | mor máa | 馬 | m |  |
| น | นอ หนู | nor nŏo | 老鼠 | n |  |
| ย | ยอ ยักษ์ | yor yák | 巨人 | y |  |
| ว | วอ แหวน | wor wăen | 戒指 | w |  |
| ง | งอ งู | ngor ngoo | 蛇 | ng |  |
| ล | ลอ ลิง | lor ling | 猴子 | l |  |

| ญ | ญอ หญิง | yor yĭng | 女性 | y |  |
| ฬ | ฬอ จุฬา | lor jù-laa | 風箏 | l |  |


作業：ม、น、ย、ว、ง、ล、ร、ณ、ญ、ฬ、น้ำ、แม่、รู้、เยอะ、ว่า、ง้อ、ทะเล、กีฬา、ไม่ใช่

## L9 ห 補齊 LCs 的音調

LCs 沒有同音高子音，缺少的聲調在前面加 ห（不發音）來補齊。


單字：หมา 狗、หมี 熊、หล่อ 帥、หนู 老鼠、หมู 豬、เหล้า 酒、หมอ 醫生、หน้า 臉、เหมาะ 適合、หรือ 或是、เหงา 寂寞、ไหม 嗎、ใหม่ 新的、ใหญ่ 大的、ไหน 哪

作業：เมาเหล้า、หน้าตา、กะหรี่、เหงา、ใหญ่、หรือ、หมู、หล่อ、หมอ、ใหม่、造句作業：用 ___หรือ___ 與 ___ไหม 各造一句

## L10 清尾音

尾音 m、n、y、w、ng 共 5 個音、10 個字；有清尾音時，不論長短音，都依長音的規則。


單字：สาม 三、ถาม 問、ผอม 瘦、ชาม 碗、ชาย 男、ตาย 死、ไทย 泰、สาว 年輕女、เที่ยว 遊玩、ข้าว 飯、แก้ว 杯、สอง 二、ของ 東西、น้อง 弟妹、บ้าน 家、แฟน 另一半、หวาน 甜、กาล 時辰、อาหาร 食物、คุณ 你、กัญชา 大麻、วาฬ 鯨魚、จาน 盤子、เพื่อน 朋友

作業：พี่สาว、น้องชาย、ไปเที่ยว、กินข้าว、จาน、เพื่อนบ้าน、ข้าวเหนียว、หมูปิ้ง、คุณ、สาม、點餐造句：要＿份＿／要＿盤＿／要＿碗＿
